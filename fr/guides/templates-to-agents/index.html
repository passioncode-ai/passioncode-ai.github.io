Comment les modèles d’agents deviennent vos agents

Nous ne construisons pas vos agents à partir de zéro. Chacun part d’un modèle qui contient ce que nous avons appris en faisant tourner des agents de ce type, et il est assemblé pour vos processus.

Sergey Sheleg, cofondateur de PassionCode.ai

Ce qu’est un modèle

Un modèle décrit un type d’agent : le travail qu’il fait, les règles qu’il respecte, ce qu’il ne doit jamais faire et quand il appelle une personne, avec du code testé derrière. Il rassemble ce qu’ont appris les agents de ce type que nous faisons tourner dans notre propre travail. Voir les modèles d’agents.

De votre demande à un agent

Vous nous dites ce que les agents doivent faire. Notre agent ingénieur choisit le modèle adapté, connecte vos systèmes avec les accès que vous accordez, fixe vos règles et vos limites de dépenses, et vérifie l’agent sur vos propres processus avant qu’il se mette au travail.

Où il tourne

Sur vos machines ou dans votre propre cloud, avec vos clés. Chaque agent affiche son état et ce qu’il dépense, et une personne approuve ce qui demande une personne : un paiement, une mise en production pour de vrais utilisateurs, un message à quelqu’un d’extérieur.

Ce qui reste à vous

Vos données, vos clés et vos agents. La bibliothèque de modèles reste la nôtre : vous recevez les agents assemblés, pas la bibliothèque, et nous partageons les détails d’un modèle quand nous discutons de votre demande.

Des agents qui s’améliorent

Quand nous améliorons un modèle, l’amélioration peut atteindre votre agent avec la version suivante du modèle, après les vérifications que votre agent passe déjà.
