LE CHEMIN

D’un seul agent
à une organisation AI-native

Commencez par un agent pour une tâche. Ajoutez le suivant quand le travail le demande. Ils rejoignent une même famille que vous pouvez voir, à laquelle vous pouvez vous fier et que vous pouvez agrandir, et cette famille grandit avec votre équipe.

  1. 01

    DISPONIBLE MAINTENANT

    Un agent

    Vous construisez un agent pour une tâche avec Claude Code, Codex ou un autre agent de code. Le skill Fabric Agent Adapter lui donne un contrat, un tableau de bord et des tests.

  2. 02

    DISPONIBLE MAINTENANT

    Deux agents qui se parlent

    Les agents connectés à Fabric partagent le tableau, la mémoire et les passations d’un même projet : l’un reprend là où l’autre s’est arrêté, et vous lisez chaque passation.

  3. 03

    ORIENTATION

    Une chaîne

    Les agents s’enchaînent en un seul processus : l’un prépare, le suivant vérifie, une personne valide.

  4. 04

    DISPONIBLE EN PARTIE

    Une famille qui veille sur elle-même

    Fabric Dashboards affiche l’état et les dépenses de chaque agent, les outils se mettent à jour d’eux-mêmes, et Project Observatory garde ce qui a changé et ce qui a été décidé. Des agents qui veillent les uns sur les autres, c’est la direction.

  5. 05

    ORIENTATION

    Une équipe

    Vous invitez des personnes dans les mêmes boucles : chacune reçoit un espace de travail, les agents de son rôle et ce qu’elle a le droit de faire.

  6. 06

    ORIENTATION

    Une organisation

    Les agents arrivent sur chaque poste de travail, les personnes vérifient leur travail et construisent leurs propres agents, et l’organisation voit comment le travail se déroule.

LA VISION

Faites ce que vous aimez
Les agents s’occupent du reste

Cessez d’assembler des chaînes d’outils, d’apprendre comment chaque pièce s’emboîte et de faire à la main le travail qu’une machine pourrait faire. Commencez par des mots — « fais-moi ce dont j’ai besoin » — et laissez l’espace de travail grandir avec vous. Chaque agent vous retire une tâche routinière de plus, et chaque semaine laisse davantage de place au travail que vous aimez vraiment.

  • Rien pour commencerDes mots, pas des pipelines. Vous décrivez le résultat ; les agents construisent les étapes.
  • Local et open sourceSur vos machines, dans un code que tout le monde peut lire, sous licence GNU AGPL-3.0.
  • Sûr dès la conceptionVous fixez ce que chaque agent a le droit de faire, et chaque action laisse une trace.
  • À façonner à votre guiseDe rien à n’importe quoi, configuré à la main ou par des agents.
  • N’importe quel agentClaude Code, Kilo Code et Hermes Agent se connectent déjà à Fabric, Codex et Cline tournent à l’intérieur, et d’autres agents sont prévus. Quels agents, à quel niveau

Où nous en sommes aujourd’hui : vous commencez avec une commande et votre agent de code. Commencer par une conversation avec Fabric, c’est la direction que prend Fabric.

01 / COMMENT ÇA MARCHE

D’un Mac vierge
à des agents au travail

Quatre étapes, chacune utile à elle seule. Commencez par celle dont vous avez besoin et ajoutez le reste quand le travail l’exige.

  1. 01

    Créez votre espace de travail

    Installez les skills pour agents en une commande, puis ajoutez Fabric : l’agent IA dans le rôle de CEO, qui réunit en un seul endroit l’objectif, le tableau des tâches, les décisions et les versions de chaque projet.

    npx @passioncode-ai/passioncode@latest update

    Préversion de Fabric 0.3.3 pour macOS sur Apple silicon · lanceur 0.1.31

    Guide pas à pas →
  2. 02

    Créez des agents

    Demandez à Claude Code ou Codex l’agent dont vous avez besoin : publier les versions, trier les demandes de support, produire un rapport hebdomadaire. Le skill Fabric Agent Adapter le construit comme un service avec son propre contrat, son tableau de bord et ses tests. Fabric le fera pour vous à partir d’une conversation ; aujourd’hui, c’est votre agent de code qui s’en charge, avec le même skill.

    vous Créez un agent Fabric qui rédige les notes de version à partir des pull requests fusionnées

  3. 03

    Adaptez ce que vous avez déjà

    Un agent, un serveur MCP, un outil en ligne de commande ou un projet entier devient un service compatible avec Fabric, sans réécriture. La sonde de conformité vous indique ce qui manque.

    vous Adaptez ce dépôt à Fabric

    Fabric Agent Adapter 0.8.1 · Fabric Agent Contract

  4. 04

    Lancez-les et gardez tout sous les yeux

    Fabric Dashboards affiche tous les services dans une seule fenêtre et permet aux agents de les démarrer et de les arrêter. Switchboard choisit le compte sur lequel tourne chaque agent. Project Observatory montre ce qui a changé dans chaque projet, preuves à l’appui.

    Choisir les outils ↓

07 / QUESTIONS

Les questions qu’on nous pose d’abord

PassionCode.ai est-il gratuit ?

Oui. Chaque outil est open source sous licence GNU AGPL-3.0 : vous pouvez le télécharger, l’utiliser, l’étudier et le modifier gratuitement. Une licence commerciale est disponible si vous l’intégrez à un produit fermé ou si vous exploitez une version modifiée en service hébergé sans en publier le code source.

Avec quels agents fonctionne-t-il ?

Il n’est lié à aucun agent. Claude Code, Kilo Code et Hermes Agent se connectent déjà à Fabric, Codex et Cline tournent à l’intérieur, et d’autres sont prévus : la liste complète, par niveau. Avec Fabric Agent Adapter, n’importe quel agent, serveur MCP ou outil en ligne de commande peut devenir un service compatible avec Fabric.

Comment transformer un projet ou un agent existant en agent Fabric ?

Installez le lanceur PassionCode.ai (npx @passioncode-ai/passioncode@latest update), puis demandez à votre agent de code d’adapter le projet à Fabric. Le skill Fabric Agent Adapter en fait un service doté d’un contrat, d’un tableau de bord et d’un contrôle de conformité. Le guide détaille les étapes.

Fabric crée-t-il des agents tout seul ?

Pas encore. Fabric est en préversion : il conserve le tableau des tâches, les décisions et les versions de chaque projet, et sa conversation ne répond pas encore. Créer des agents à partir d’une conversation, c’est la direction ; aujourd’hui, c’est votre agent de code qui le fait, avec le skill Fabric Agent Adapter.

Où vont mes données ?

Votre travail reste sur vos ordinateurs et dans vos propres comptes cloud. Fabric Switchboard et, depuis la version 0.3.2, Fabric envoient des compteurs d’utilisation anonymes : uniquement des nombres et des types, jamais de noms, de chemins ni de contenu. Désactivez-les dans la fenêtre À propos de Switchboard ou dans les réglages de Fabric. Ce qui est envoyé, précisément.

PassionCode.ai peut-il mettre cela en place dans mon entreprise ?

Oui. Décrivez votre équipe et vos processus: nous vous répondons avec une estimation et une proposition, soit un accompagnement à la mise en place, soit un espace de travail que nous construisons et gérons pour vous.
