TRZY SPOSOBY PODŁĄCZENIA

Jak podłącza się każdy agent

Każdy agent poniżej może korzystać z narzędzi Switchboard: widzi, które konto obsługuje jego żądania i ile przydziału zostało, i może przełączać konta. Agenty, którym można podać własny endpoint, mogą też wysyłać żądania przez Switchboard, który przełącza konta za nie. Niektóre można uruchamiać bezpośrednio ze Switchboard.

  • Tylko narzędzia. Agent łączy się z narzędziami Switchboard, a jego żądania trafiają do jego własnej usługi.
  • Przez Switchboard. Konfigurujesz raz w agencie; Switchboard wypisze dokładne linie.
  • Uruchomienie ze Switchboard. Switchboard uruchamia agenta w folderze projektu, na kontach tego folderu.

Logowanie subskrypcją zostaje przy Claude Code i Codex, jak wymagają Anthropic i OpenAI. Pozostałe agenty używają kont z kluczem API. Konta projektu obsługują tylko foldery tego projektu.
