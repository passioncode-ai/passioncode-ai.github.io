Start your agent workplace in 20 minutes

What happens at each step of setting up the tools on your own computer, from the one command to your first agent and the next one.

Sergey Sheleg, co-founder of PassionCode.ai

What you need

A computer with Node.js 18 or newer, and Claude Code or Codex. Fabric, the home for your projects and their agents, is an early preview and also needs Docker and the Supabase CLI on every system. Everything is open source and free for personal use.

Run one command

On macOS, one command installs the tools you choose from their signed releases, connects their MCP servers to your coding agent and adds the skills. On Windows and Linux, download the apps from their pages first, then run the same command for the skills and the MCP servers. It installs nothing whose signature or checksum fails. You can also hand the job to your coding agent: the command and a prompt for your coding agent are on the Get started page.

Restart your coding agent and check

Restart Claude Code or Codex so it picks up the new tools. Run the same command again, or doctor to check without changing anything: it tells you what is set up, what is missing and the steps only you can take, such as signing in.

Create or adapt your first agent

Ask your coding agent for what you need, in plain words, or start from Fabric’s Create and Adapt actions. The Fabric Agent Adapter skill asks its questions first and shows its plan before it changes anything. You get an agent with a contract, a dashboard and tests.

See it run

Fabric Dashboards shows every local agent service in one window: what it is doing and what it spends. Your coding agent can start, stop and open them for you.

Add the next agent to the same project

Build the next agent the same way and give it the same project in Fabric. Agents connected to Fabric share one project’s board, memory and hand-offs, so one picks up where the other stopped.

If something does not work

Run the command again: on a computer that is already set up, it checks everything, repairs what is wrong and shows what changed. Each product page lists its requirements and limits.
