FABRIC · ПОДДЕРЖИВАЕМЫЕ АГЕНТЫ

Агенты для программирования,
с которыми работает Fabric

Каких агентов Fabric может запустить в вашем проекте, какие из них получают собственные инструменты Fabric и какие на очереди

На 8 октября 2026 года · выпущенное приложение — Fabric 0.3.2

В выпущенном приложении Fabric подключает Claude Code, Kilo Code и Hermes Agent: запускает агента в терминале проекта и даёт ему инструменты Fabric на эту сессию. Codex и Cline работают в Fabric, но инструментов Fabric у них пока нет. Следующими в плане идут ещё пять агентов, за ними — остальные из списка ниже. Fabric Switchboard переключает аккаунты по подписке для Claude Code и Codex, а для остальных агентов — аккаунты с ключами API через Switchboard.

01 / ЧТО ЗНАЧИТ «РАБОТАЕТ С»

Три уровня
У каждого агента — один

«Работает с Fabric» может значить разное, поэтому для каждого агента здесь указан уровень.

ПОДКЛЮЧЁН

Запускается с инструментами Fabric

Fabric запускает агента в терминале проекта. Только на эту сессию агент получает собственные инструменты Fabric: захват задач, передачу, память и доску. Доступ даёт ключ на одну сессию, и в собственные настройки агента ничего не записывается.

РАБОТАЕТ В FABRIC

Запускается в папке проекта

Fabric запускает агента в папке проекта, так что он работает с файлами этого проекта. Инструментов Fabric у него пока нет.

В ПЛАНАХ

В плане, по порядку

Мы собираемся подключить агента. План ниже задаёт порядок, а не сроки.

Kilo Code берёт настройки сессии из переменной KILO_CONFIG_CONTENT, и собственный kilo.json проекта не может их переопределить. Это проверено 5 октября 2026 года на Kilo 7.4.17. Hermes Agent подключается по открытому протоколу Agent Client Protocol: Fabric открывает его сессию и передаёт ему инструменты Fabric через локальный мост — проверено в тот же день на Hermes 0.21.4. Прежде чем Hermes сможет отвечать, в его собственных настройках нужно выбрать модель.

05 / КАК ПОДКЛЮЧАЮТСЯ ЗАПЛАНИРОВАННЫЕ АГЕНТЫ

Один открытый протокол
для запланированных агентов

Запланированные агенты подключаются по протоколу Agent Client Protocol (ACP). При настройке сессии он передаёт её MCP-серверы, и Fabric может управлять любым агентом, который его поддерживает.

06 / ПОЧЕМУ ЭТИ АГЕНТЫ

Выбраны по тому,
чем пользуются люди

Мы выбрали их по открытому рейтингу приложений OpenRouter по состоянию на 5 октября 2026 года. В его ежедневном топ-30 пятнадцать позиций — агенты для программирования или обвязки для агентов. Самая большая доля — у Hermes Agent, который подключён начиная с Fabric 0.3.2.

07 / АККАУНТЫ

Переключение аккаунтов
сегодня — Claude Code и Codex

Fabric Switchboard переключает аккаунты по подписке для Claude Code и Codex. С версии 0.6.1 он работает и с другими агентами: каждый получает инструменты Switchboard, а агент, которому можно задать свой адрес API, может отправлять запросы через Switchboard, и тот переключает его аккаунты с ключами API.
