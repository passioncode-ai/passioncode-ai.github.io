Как подключается каждый агент

Каждый агент ниже может пользоваться инструментами Switchboard: он видит, какой аккаунт обрабатывает его запросы и сколько квоты осталось, и может переключать аккаунты. Агенты, которым можно задать свой адрес API, могут ещё и отправлять запросы через Switchboard, а он переключает аккаунты за них. Некоторых можно запускать прямо из Switchboard.

  • Только инструменты. Агент подключается к инструментам Switchboard, а его запросы идут в его собственный сервис.
  • Через Switchboard. Настраивается один раз в агенте; нужные строки Switchboard выведет сам.
  • Запуск из Switchboard. Switchboard запускает агента в папке проекта на аккаунтах этой папки.

Вход по подписке остаётся за Claude Code и Codex, как того требуют Anthropic и OpenAI. Остальные агенты используют аккаунты с ключами API. Аккаунты проекта обслуживают только папки этого проекта.
