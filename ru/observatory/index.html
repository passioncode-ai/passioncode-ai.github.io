ВНУТРИ OBSERVATORY

Сначала — то, что требует внимания

Настоящий обзор Observatory, построенный движком по проектам вымышленной компании.

ЛОКАЛЬНАЯ ОБСЕРВАТОРИЯ

Меньше догадок
Больше фактов с одного взгляда

01 / РЕЕСТР

Знайте, что у вас есть

Выберите папку с проектами, за которой хотите наблюдать. Observatory найдёт в ней репозитории и будет вести локальный реестр, указывая, по какому правилу установлена каждая связь.

02 / АКТИВНОСТЬ

Смотрите, что изменилось

Коммиты, состояние рабочего дерева и работа, которая есть только на этой машине, — по всем отслеживаемым проектам, с понедельной картиной по каждому.

03 / НАХОДКИ

Начинайте с важного

Находки приходят с основанием и следующим шагом, от критичных до информационных. У заглушённых находок сохраняется, кто их заглушил, когда и почему.

04 / КЛЮЧИ

Находите копии известных ключей

Метаданные учётных данных хранятся отдельно от значений. Выбранные транскрипты, логи и хранилища SQLite сравниваются с ключами, уже известными локально; само значение в находках никогда не показывается.

05 / ВАШ ЯЗЫК

Английский или русский

По умолчанию дашборд на английском. Включите русский для рабочего пространства или переключайтесь кнопкой EN/RU на боковой панели; у счётчиков правильные формы множественного числа для каждого языка.

06 / АГЕНТЫ

Дайте следующему агенту контекст

CLI, инструменты MCP и плагин для Claude Code опираются на одни и те же локальные факты. Интеграции и фоновые задачи выключены, пока вы их не выберете.

СКАЧАТЬ OBSERVATORY

Начните со своего рабочего пространства

Последний релиз: 0.19.4. Для первого локального наблюдения ключ API не нужен. Поручите установку своему агенту для программирования или выполните её сами.

  1. 01

    Установите релиз

    Скачать project_observatory-0.19.4-py3-none-any.whl и SHA256SUMS из релиза 0.19.4, проверить их командой shasum -a 256 -c SHA256SUMS --ignore-missing, затем в изолированном окружении Python 3.11+ с поддержкой расширений SQLite выполнить pip install --no-deps для wheel, а потом для его дополнения [full] с -c "$(project-observatory full-path)/requirements-full.lock" — это набор зависимостей, с которым релиз тестировался. На macOS используйте Python из Homebrew.

  2. 02

    Создайте личное рабочее пространство

    project-observatory full init, затем выберите папку для наблюдения командой full configure sources projects. Конфигурация, ключи и история хранятся отдельно от установленного кода.

  3. 03

    Наблюдайте и открывайте

    project-observatory full local, затем full open. Для русского языка: full configure interface locale ru.

  4. 04

    Подключите агента

    MCP-сервер работает через stdio: claude mcp add observatory --scope user -e OBSERVATORY_HOME="$OBSERVATORY_HOME" -- "$(python -c 'import sys; print(sys.executable)')" "$(project-observatory full-path)/mcp/server.py", затем попросите observatory_overview.

Приложение для Mac: ProjectObservatory-0.19.4-macos.zip, подписано Developer ID и нотаризовано Apple, для macOS 14+. Оно открывается на дашборде и использует движок, установленный выше; проверьте его по тому же SHA256SUMS.

Текущий релиз, 0.19.4, выпущен под AGPL, как и все релизы начиная с 0.10.0 — первого под AGPL; 0.9.1 и более ранние сохраняют лицензию, с которой вышли.

Поиск известных значений сравнивает выбранные артефакты с ключами, уже известными локально. Он не может найти неизвестные секреты или доказать, что копий не осталось, а локальная копия — не доказательство того, что ключ попал к кому-то ещё. Ротация ключей у реальных провайдеров и внешние MCP-хосты в офлайн-набор тестов не входят.

ПЕРЕД НАЧАЛОМ

Что важно различать

Observatory выгружает куда-то мои проекты или ключи?

Нет. Реестр, история и наблюдения хранятся в вашем личном рабочем пространстве на вашей машине. У необязательных интеграций свой доступ; каждая включается отдельно и с вашим собственным аккаунтом.

Что он читает?

Только те папки и источники, которые вы настроили. full doctor сообщает, что включено и чего не хватает, а дашборд прямо говорит, что источник не измерялся, вместо того чтобы показать ноль.

Это то же самое, что Switchboard?

Нет. Switchboard управляет вашими аккаунтами Claude Code и Codex. Observatory держит на виду проекты, над которыми работают эти агенты. Оба — инструменты PassionCode с открытым кодом, которыми можно пользоваться уже сегодня.

А Fabric?

Fabric — наш ИИ-агент в роли CEO, сейчас в ранней предварительной версии; его задача — координировать агентов и проекты. Observatory доступен уже сейчас как отдельный локальный инструмент. Подробнее о Fabric.

Можно ли изучить или собрать его самому?

Да. Project Observatory — открытый код под GNU AGPL-3.0. Для использования, которое AGPL не покрывает, коммерческую лицензию можно получить на passioncode.ai/business. Выпущенные версии сохраняют свою лицензию: 0.8.1 и более ранние — MIT, с 0.8.2 по 0.9.1 — PolyForm Noncommercial или Internal Use. В репозитории есть исходный код, тесты, модель безопасности и заметки к релизам.
