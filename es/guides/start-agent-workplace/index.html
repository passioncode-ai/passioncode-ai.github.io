Guía · 8 de noviembre de 2026

Pon en marcha tu espacio de trabajo de agentes en 20 minutos

Qué ocurre en cada paso al configurar las herramientas en tu propio ordenador, desde el único comando hasta tu primer agente y el siguiente.

Sergey Sheleg, cofundador de PassionCode.ai

Qué necesitas

Un ordenador con Node.js 18 o posterior, y Claude Code o Codex. Fabric, el hogar de tus proyectos y sus agentes, es una vista previa temprana y además requiere Docker y la CLI de Supabase en todos los sistemas. Todo es de código abierto y gratuito para uso personal.

Ejecuta un comando

En macOS, un comando instala las herramientas que elijas desde sus versiones firmadas, conecta sus servidores MCP a tu agente de programación y añade las skills. En Windows y Linux, descarga primero las aplicaciones desde sus páginas y luego ejecuta el mismo comando para las skills y los servidores MCP. No instala nada cuya firma o suma de comprobación falle. También puedes encargarle el trabajo a tu agente de programación: el comando y un prompt para tu agente de programación están en la página Empezar.

Reinicia tu agente de programación y comprueba

Reinicia Claude Code o Codex para que cargue las herramientas nuevas. Ejecuta de nuevo el mismo comando, o doctor para revisar sin cambiar nada: te dice qué está configurado, qué falta y los pasos que solo tú puedes dar, como iniciar sesión.

Crea o adapta tu primer agente

Pide a tu agente de programación lo que necesitas, con palabras sencillas, o empieza desde las acciones de Fabric para crear y adaptar. La skill Fabric Agent Adapter hace primero sus preguntas y muestra su plan antes de cambiar nada. Obtienes un agente con un contrato, un panel y pruebas.

Míralo funcionar

Fabric Dashboards muestra cada servicio de agente local en una sola ventana: lo que está haciendo y lo que gasta. Tu agente de programación puede iniciarlos, detenerlos y abrirlos por ti.

Añade el siguiente agente al mismo proyecto

Crea el siguiente agente del mismo modo y dale el mismo proyecto en Fabric. Los agentes conectados a Fabric comparten el tablero, la memoria y los traspasos de un proyecto, así que uno retoma donde lo dejó el otro.

Si algo no funciona

Vuelve a ejecutar el comando: en un ordenador que ya está configurado, lo revisa todo, repara lo que está mal y muestra qué cambió. Cada página de producto indica sus requisitos y límites.
