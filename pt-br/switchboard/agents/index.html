TRÊS FORMAS DE ENTRAR

Como cada agente se conecta

Todos os agentes abaixo podem usar as ferramentas do Switchboard: ele vê qual conta atende às suas requisições e quanta cota resta, e pode trocar de conta. Os agentes que aceitam um endpoint personalizado também podem enviar as requisições pelo Switchboard, que troca de conta por eles. Alguns podem ser iniciados diretamente pelo Switchboard.

  • Somente ferramentas. O agente se conecta às ferramentas do Switchboard; as requisições dele vão para o serviço do próprio agente.
  • Pelo Switchboard. Configure uma vez no agente; o Switchboard mostra as linhas exatas.
  • Início pelo Switchboard. O Switchboard inicia o agente em uma pasta de projeto, com as contas dessa pasta.

Os logins por assinatura ficam com o Claude Code e o Codex, como a Anthropic e a OpenAI exigem. Os outros agentes usam contas com chave de API. As contas de um projeto atendem somente as pastas desse projeto.
