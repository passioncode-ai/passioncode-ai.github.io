# Brand assets used by the public site

The passion-fruit mark is the approved PassionCode.ai vector. These are the small,
deployable aliases used by the website; the complete approved snapshot lives in
[`../brand/`](../brand/README.md). PNG files support metadata and platform surfaces;
`passioncode-social-card.svg` is the 1200×630 social composition and the PNG/JPG files
beside it are its exports.

Do not redraw or edit these files directly. `npm run check` proves they are byte-identical
to the locked snapshot and fails if either copy drifts.
