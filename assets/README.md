# Brand assets used by the public site

The passion-fruit mark is the approved PassionCode.ai vector from the private Fabric
brand pack. `passioncode-mark.svg` is the canonical web copy. PNG files are generated
exports for metadata and platform surfaces; `passioncode-social-card.svg` is the editable
1200×630 social composition and the PNG/JPG files beside it are derived exports.

Do not redraw the mark inside product or campaign files. Update the canonical Fabric
source first, then propagate and regenerate these copies.
