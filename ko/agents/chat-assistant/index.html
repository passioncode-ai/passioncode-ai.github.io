01 / 기능

기능

  • 기억하는 대화대화와 장기 기억을 유지하고, 답변을 스트리밍합니다.
  • 도구와 음성도구를 쓰고, 듣고 말하며, 들어오고 나가는 내용을 검토합니다.
  • 사용량 계량사용자별 한도, 크레딧 또는 구독, 그리고 자체 지출을 추적합니다.

02 / 대상

대상

어시스턴트를 기능으로 제공하는 제품, 그리고 자체 채팅에 어시스턴트를 두려는 팀에 적합합니다.

얻는 것

  • 맥락을 기억하는 어시스턴트
  • 사용자별로 관리되는 비용
  • 민감한 순간의 신중한 처리

03 / 구성 방식

템플릿이
조직의 에이전트가 되기까지

템플릿에는 저희가 이런 종류의 에이전트를 운영하며 배운 것이 담겨 있습니다. 저희 엔지니어 에이전트가 조직에 맞춰 구성하며, 세부 내용은 요청 시 제공합니다.

  1. 01

    조직의 프로세스에서 시작합니다

    에이전트가 무엇을 해야 하는지 알려 주세요. 저희는 에이전트가 맡을 일, 필요한 시스템, 누가 무엇을 승인하는지 살펴봅니다.

  2. 02

    저희 엔지니어 에이전트가 구성합니다

    알맞은 템플릿을 골라, 허용하신 접근 권한으로 조직의 시스템을 연결하고, 조직의 규칙과 지출 한도를 설정합니다.

  3. 03

    원하는 곳에서 실행됩니다

    조직의 컴퓨터나 자체 클라우드에서, 조직의 키로 실행됩니다. 각 에이전트는 상태와 지출을 보여 주며, 사람이 필요한 일은 사람이 승인합니다.
