20분 만에 에이전트 업무 공간 시작하기

내 컴퓨터에 도구를 설정할 때 각 단계에서 무슨 일이 일어나는지, 명령 하나부터 첫 에이전트와 그다음 에이전트까지 안내합니다.

Sergey Sheleg, PassionCode.ai 공동 창업자

필요한 것

Node.js 18 이상이 설치된 컴퓨터, 그리고 Claude Code 또는 Codex가 필요합니다. 내 프로젝트와 그 에이전트를 위한 집인 Fabric은 초기 프리뷰이며, 모든 시스템에서 Docker와 Supabase CLI도 필요합니다. 모두 오픈 소스이며 개인 사용은 무료입니다.

명령 하나 실행하기

macOS에서는 명령 하나가 선택한 도구를 서명된 릴리스에서 설치하고, 그 MCP 서버를 코딩 에이전트에 연결하며, 스킬을 추가합니다. Windows와 Linux에서는 먼저 각 페이지에서 앱을 다운로드한 뒤, 스킬과 MCP 서버를 위해 같은 명령을 실행하세요. 서명이나 체크섬 확인에 실패한 것은 아무것도 설치하지 않습니다. 이 작업을 코딩 에이전트에게 맡길 수도 있습니다: 명령과 코딩 에이전트용 프롬프트는 시작하기 페이지에 있습니다.

코딩 에이전트를 다시 시작하고 점검하기

새 도구를 인식하도록 Claude Code나 Codex를 다시 시작하세요. 그다음 같은 명령을 다시 실행하거나 doctor 명령으로 아무것도 바꾸지 않고 점검하세요: 무엇이 설정되었는지, 무엇이 빠졌는지, 그리고 로그인처럼 직접 해야만 하는 단계를 알려 줍니다.

첫 에이전트 만들기 또는 맞추기

필요한 것을 평범한 말로 코딩 에이전트에게 요청하거나, Fabric의 Create와 Adapt 작업에서 시작하세요. Fabric Agent Adapter 스킬은 먼저 질문하고, 무엇이든 바꾸기 전에 계획을 보여 줍니다. 계약, 대시보드, 테스트를 갖춘 에이전트가 만들어집니다.

실행되는 모습 확인하기

Fabric Dashboards는 모든 로컬 에이전트 서비스를 한 창에서 보여 줍니다: 무엇을 하고 있는지, 얼마를 쓰는지. 코딩 에이전트가 대신 서비스를 시작하고, 중지하고, 열 수 있습니다.

같은 프로젝트에 다음 에이전트 추가하기

다음 에이전트도 같은 방식으로 만들고 Fabric의 같은 프로젝트를 주세요. Fabric에 연결된 에이전트는 한 프로젝트의 보드, 메모리, 인계를 공유하므로, 한 에이전트가 멈춘 곳에서 다른 에이전트가 이어받습니다.

작동하지 않을 때

명령을 다시 실행하세요: 이미 설정된 컴퓨터에서는 모든 것을 점검하고, 잘못된 것을 고치고, 무엇이 바뀌었는지 보여 줍니다. 각 제품 페이지에 요구 사항과 제한이 나와 있습니다.
