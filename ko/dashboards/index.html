01 / 작업을 한눈에

작업을 수행하는 도구를
들여다보는 창

Fabric Dashboards는 Mac에서 호환되는 서비스를 찾아냅니다. 각 서비스는 자기 역할을 그대로 유지하고, 사용자는 서비스를 함께 점검하고 제어할 공용 공간을 얻습니다.

확인이 필요한 항목 보기

서비스 상태, 최근 활동, 확인이 필요한 항목이 함께 표시됩니다. 느린 응답은 곧바로 장애로 처리되지 않습니다.

실제 대시보드 열기

각 서비스의 인터페이스가 로그인된 상태로 앱 안에서 열립니다. Project Observatory는 지금 사용할 수 있는 호환 서비스 중 하나입니다.

다음 단계 처리

서비스를 시작, 중지, 재시작하고 로그를 확인하며, 서비스 계약이 제공하는 동작을 사용할 수 있습니다. Dashboards를 종료해도 서비스는 계속 실행됩니다.

0.6 업데이트

Spend, 콘솔,
믿을 수 있는 업데이트

2026년 10월 6일의 0.6.0부터 10월 8일의 0.6.5까지, 0.6 릴리스에서 추가된 내용입니다.

Spend에서 모든 한도 확인

Spend 페이지에는 각 에이전트에 적용된 한도가 나열됩니다. 가장 확인이 필요한 한도는 작업이 멈췄거나 기준선을 넘으면 빨간색, 80%에 이르면 주황색으로 표시되며, 에이전트를 펼치면 모든 한도와 해당 기간, 사용한 금액을 볼 수 있습니다. 에이전트도 MCP로 같은 목록을 읽습니다.

대시보드 옆의 에이전트 콘솔

서비스 대시보드 옆에 실제 터미널이 열리고, 해당 에이전트의 저장소에서 Claude Code, Codex 또는 다른 런타임이 실행됩니다. Fabric Switchboard가 폴더를 프로젝트에 연결해 둔 경우, 세션은 그 프로젝트의 계정으로 시작됩니다.

먼저 검증하는 업데이트

앱은 스스로 업데이트합니다. 릴리스는 설치 전에 조직의 서명을 갖추고 체크섬과 일치해야 하며, 콘솔이나 명령이 실행되는 동안에는 기다립니다. 자동 설치는 설정에서 끌 수 있습니다.

최신 상태로 유지되는 패밀리

설정 → Estate updates는 Fabric Agent Contract와 PassionCode.ai 스킬을 감시하며, 게시한 주체를 확인한 뒤 백그라운드에서 스킬을 업데이트할 수 있습니다. 이 스위치는 기본적으로 꺼져 있습니다.

영어 또는 러시아어

설정 → 언어: 이 Mac의 설정에 따라 English 또는 Русский입니다. 창, 메뉴, 트레이가 한 번에 전환됩니다.

Fabric Dashboards 다운로드 ↓

DMG를 열고 Fabric Dashboards를 응용 프로그램 폴더로 드래그한 다음 실행합니다. 앱은 로그인할 때 시작되며, 설정에서 바꿀 수 있습니다.

열기 전에

서비스는 별도로 설치합니다. 호환되는 서비스를 설치하기 전에는 목록이 비어 있는 것이 정상이며, Dashboards가 모든 로컬 프로세스를 에이전트 서비스로 바꾸지는 않습니다.

먼저 Project Observatory를 써 보거나, Fabric Agent Adapter로 직접 서비스를 만들 수 있습니다. 앱 자체에는 계정이나 API 키가 필요하지 않습니다.

03 / 에이전트용

같은 서비스를
에이전트에서

앱의 MCP 서버를 클라이언트에 등록합니다. 에이전트는 서비스 목록을 보고, 대시보드 링크를 받고, 앱의 규칙이 허용하는 동작을 사용할 수 있습니다.

claude mcp add --scope user fabric-dashboards -- "/Applications/Fabric Dashboards.app/Contents/Resources/bin/fabric-dashboards-mcp"

앱을 응용 프로그램 폴더에 설치한 뒤 에이전트에게 다음 호출을 요청하세요: list_services. 결과가 비어 있으면 아직 설치된 서비스가 없다는 뜻입니다. 다른 MCP 클라이언트는 같은 실행 파일을 stdio 서버로 실행할 수 있습니다. 자세한 내용: MCP 설정 가이드.

04 / 알아 두면 좋은 점

내 환경에 맞게

Fabric이 필요한가요?

아닙니다. Fabric Dashboards는 단독으로 동작합니다. Fabric의 도구 중 하나이며, Fabric 초기 프리뷰를 사용하기 전에도 호환되는 서비스를 보여 줄 수 있습니다.

어떤 서비스가 표시되나요?

다음 규격의 로컬 디스크립터를 게시하는 서비스입니다: fabric-service/0.1. Project Observatory가 이를 지원합니다. 프로토콜은 Fabric Agent Contract에서 정의하며, Adapter가 구현을 도와줍니다.

오픈 소스인가요?

Fabric Dashboards는 GNU AGPL-3.0 오픈 소스입니다. 상용 라이선스도 있습니다: passioncode.ai/business. 릴리스 0.1.0은 MIT를 유지하고, 0.2.0과 0.3.0은 PolyForm Noncommercial 또는 Internal Use를 유지합니다. 릴리스 0.3.1이 AGPL을 적용한 첫 버전입니다.
