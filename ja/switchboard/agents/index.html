3つの接続方法

各エージェントの接続方法

以下のどのエージェントも Switchboard のツールを使えます。リクエストを処理しているアカウントと残りの利用枠を確認でき、アカウントを切り替えることもできます。カスタムエンドポイントを受け付けるエージェントは、リクエストを Switchboard 経由で送信でき、Switchboard がアカウントを切り替えます。一部のエージェントは Switchboard から直接起動できます。

  • ツールのみ。 エージェントは Switchboard のツールに接続し、リクエストはエージェント自身のサービスに送られます。
  • Switchboard 経由。 エージェントで一度設定するだけです。必要な行は Switchboard が表示します。
  • Switchboard から起動。 Switchboard が、プロジェクトフォルダー内で、そのフォルダーのアカウントを使ってエージェントを起動します。

サブスクリプションのサインインは、Anthropic と OpenAI の要件に従い、Claude Code と Codex に限られます。その他のエージェントは API キーのアカウントを使います。プロジェクトのアカウントは、そのプロジェクトのフォルダーでのみ使われます。
