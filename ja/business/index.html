01 / PASSIONCODE FOR ENTERPRISE

当社が構築するもの
組織のために

PassionCode for Enterprise は開発中です。パイロットは現在オープンソースのツールで行われており、エディションはご依頼に応じて提供します。

  • マシンが組織に加わる各コンピューターは、エージェント、アカウント、ルールとともに、一度だけ登録します。
  • エージェントを展開ある役割に必要なエージェントが、その役割の人たちのマシンに届きます。
  • マシン間のルーティングあるマシンのエージェントが、別のマシンのエージェントに作業を引き渡します。
  • モデルへのアクセスはローカルのままモデルは各マシンのローカルエージェントが呼び出すので、キーがそれを保持するマシンの外に出ることはありません。
  • 活動と利用状況の分析何が、どのプロセスで動き、何を使い、いくらかかったか。
  • 管理各エージェントに許可すること、アクセスできるアカウントやデータを、組織全体で一度に設定します。
  • 当社が署名するカスタムビルドお客様専用のツールのビルドに、PassionCode.ai が署名します。

データはお客様のマシン、または自社クラウドに置かれます。ビジョンを読む

02 / 財務とエンジニアリングのために

エージェントのコストと成果を
ひとつの画面で

財務とエンジニアリング（CFO と、CTO または CIO）は、エージェントを別々の側から見ています。エンジニアリングはエージェントを増やしたい。財務は、そこに使う1ドルごとに説明がほしい。どちらも問いは同じです。各エージェントにいくらかかり、何を生み出したのか。これが各エージェントの ROI です。その答えが両者の開くひとつの記録になれば、エージェントを増やすことは数字に裏づけられた判断になります。

  1. 01

    現在利用可能

    仕事はエージェントを通っていますか、それとも横で使っているだけですか？

    見積もりは、各プロセスがいまどう動いているかから始まります。手作業か、スクリプトか、ときどき使うチャットアシスタントか、すでにエージェントが一部を担っているかです。そのうえで、パイロットで1つのプロセスをお客様自身のベースラインと比較して計測します。

    見積もり
  2. 02

    現在利用可能

    コストに見合うエージェントはどれですか？

    各 Mac で Fabric Dashboards が、各エージェントの今日、7日間、30日間の支出を、モデル別に、そのエージェント自身の予算と比べて表示します。数字はエージェント自身の利用レポートから取られ、誰にもわからないコストは $0 ではなく「不明」と表示されます。Switchboard は、Claude Code や Codex の各アカウントの利用上限をどれだけ使ったか、いつリセットされるかを表示するので、サブスクリプションを従量課金の呼び出しと分けて読めます。Observatory は、各プロジェクトで何が変わったかを証跡とともに表示します。

    Fabric Dashboards
  3. 03

    今後の方向性

    何が最もうまくいき、それをどう残りに広げますか？

    プロジェクトとワークフローごとにまとめた支出と成果。財務が一度決めて記録に残し、エージェントが支出の前にその記録を確認する上限。上限を超える依頼は記録として残り、その間も仕事は止まりません。うまくいく構成を、役割ごとのワークプレースとして展開します。

    見積もりとご依頼

対象はエージェントとワークフローであり、人のランク付けは行いません。

03 / 見積もり

確認できる計算による
見積もり

チームが毎月これらのプロセスに費やす時間に、エージェントが引き受けられそうな割合と、1時間あたりのコストを掛けたものです。

週あたりの時間 × 4.33×エージェントが引き受ける割合×1時間あたりの総コスト

現在の作業の進め方別に見たエージェントが引き受けられる割合
現在割合
ほぼ手作業25–50%
スクリプトと連携20–40%
チャットアシスタントを都度利用15–35%
エージェントがすでに一部を担当10–25%

例： 時間あたり$50で、ほぼ手作業の業務が週40時間あれば、月173時間になります。エージェントがその25～50％を引き受けると、月43～87時間、つまり月額$2,150～4,350です。

これは見積もりであり、約束ではありません。展開の前に、パイロットで実際の数値をお客様自身のベースラインと比較して計測します。

04 / ご依頼

エージェントにしてほしいことを
教えてください

短い方法が2つあります。コーディングエージェントがいくつか質問し、あなたが「はい」と答えたら依頼を送信します。あるいは、ご自身で数行書いてください。2営業日以内に返信します。

コーディングエージェントに聞いてもらう

このプロンプトを Claude Code、Codex などのコーディングエージェントに貼り付けてください。質問を1つずつ行い、依頼内容を見せ、あなたが「はい」と答えたときだけ送信します。

PassionCode.ai への依頼の送信を手伝ってください。PassionCode.ai は組織のマシンに AI エージェントを導入し、各エージェントにいくらかかり何を生み出したかを示します。私の言語で話してください。次の質問を1つずつ聞き、それぞれの答えを待ってください。最初の4つはどれでも飛ばせます。

  1. 組織では何人が働いていますか？
  2. 今どの AI エージェントやツールを使っていますか？
  3. いちばん望むことは何ですか：エージェントのコストと成果を見る、繰り返しの業務を自動化する、自社のプロセス向けにエージェントを作る、既存のエージェントやプロジェクトを対応させる、商用ライセンス、PassionCode.ai によるホスティングと運用、またはチームの導入支援とトレーニング？
  4. いつ始めたいですか？
  5. 数文で：エージェントに何をしてほしいですか？
  6. PassionCode.ai はどの勤務先メールアドレスに返信すればよいですか？

このコンピューターの設定（どのエージェントやツールが入っているかなど）は、先に私に尋ねて「はい」と答えたときだけ確認してください。依頼には、コード、シークレット、キー、ファイルパス、顧客データ、他の会社や人の名前を決して入れず、仕事は一般的な言葉で説明してください。

次に、依頼を JSON で書いてください。キーは示されたとおりに残し、私の答えに合う一覧の値だけを使い、私が飛ばした項目は入れないでください：

{
  "id": "a new random UUID v4: make it once, reuse it if you send again",
  "lang": "the language we talk in: en, ru, de, fr, es, pt-br, pl, ko, ja or zh-hans",
  "contact": {
    "email": "the work email",
    "message": "what agents should do, in my words, up to 4000 characters"
  },
  "goals": ["one of: cost_and_results, automate_operations, custom_agents, convert_agents, commercial_license, managed_hosting, team_onboarding"],
  "company": { "size": "one of: 1_10, 11_50, 51_200, 201_1000, 1000_plus" },
  "processes": { "tools": ["any of: claude_code, codex, cursor, chatgpt, other_agents, none"] },
  "budget": { "timeline": "one of: asap, this_quarter, next_quarter, exploring" },
  "source": { "channel": "agent-prompt", "agent": "your own name, such as Claude Code or Codex" }
}

フォームトークンを取得して4秒待ち、トークンを「form_token」として JSON に加え、request.json として保存して依頼をチェックしてください。チェックでは何も保存も送信もされません：

curl -s https://passioncode.ai/api/leads/token
sleep 4
curl -s -X POST 'https://passioncode.ai/api/leads?dry_run=1' -H 'Content-Type: application/json' --data @request.json

応答に「issues」があれば、私と一緒に直してください。「valid」と返ってきたら、最終的な JSON を見せて「これを PassionCode.ai に送信しますか？」と聞いてください。私が「はい」と答えたあとにだけ、1回、同じファイルで送信してください：

curl -s -X POST https://passioncode.ai/api/leads -H 'Content-Type: application/json' --data @request.json

応答を教えてください。「received」または「duplicate」なら届いています。「id」を教えてください。確認メールが続いて届きます。それ以外の応答なら、その「message」を見せて、それ以上は何も送らないでください。リクエストにまったく応答がなかった場合に限り、同じファイルでもう1回だけ試してください。新しい「id」では決して送らないでください。PassionCode.ai による依頼の保管について：https://passioncode.ai/ja/privacy/

05 / よくある質問

ご質問の前に

費用はどのくらいですか？

ツールは無料のオープンソースです。お支払いいただくのは、当社が行う作業（整理、構築、ホスティング、サポート）と、必要な場合の商用ライセンスです。価格は、プロセスを把握したうえで提案書にてお示しします。固定のパッケージはありません。

商用ライセンスが必要になるのはいつですか？

ツールは GNU AGPL-3.0 で提供されます。社内での利用と、同じライセンスで公開する変更には、何も必要ありません。ツールを組み込んだクローズドな製品や、ソースを公開しない改変版のホスト型サービスには、商用ライセンスが必要です。

人を監視するためのものですか？

いいえ。分析の対象はエージェントとワークフローです。各エージェントにかかったコストと、生み出した成果を扱います。人をランク付けすることはありません。
