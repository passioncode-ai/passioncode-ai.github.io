# Channels

### landing hero
Register: confidence +1, density -1, humor -1
Format: clear role, one grounding paragraph, one primary action
Limits: none
Forbidden: physics: none | brand: unsupported scale or autonomous execution claims
CTA: concrete download or exploration path
Proof: product status and linked release
Locales: English primary

### landing body
Register: density -1, humor -1
Format: one user question per section
Limits: no claim beyond facts.md
Forbidden: physics: none | brand: private infrastructure details
CTA: source, installation or product page
Proof: facts.md and release evidence
Locales: English primary

### linkedin
Register: confidence +1, distance -1 (we, first-hand), humor -1
Format: the hook in the first two lines; one topic, 120 to 250 words: the claim, what we did or saw, what it means for a company on agents, one takeaway; text plus one image or a document carousel with sample data
Limits: at most three topic hashtags at the end; a link only when the link is the point
Forbidden: physics: none | brand: engagement bait, pods, emoji bullets, a number without source and date, direction stated as a release, private names, paths or unpublished prices
CTA: a concrete next step (read the source, set it up, bring your organization), never "agree?"
Proof: facts.md and release evidence; a result of our own says what was measured
Locales: English primary

### x
Register: confidence +1, density +1, humor -1
Format: one idea within 280 characters; open with the claim; a thread only when each post stands alone, at most 7, numbered 1/
Limits: 280 characters a post; at most one hashtag
Forbidden: physics: none | brand: decorative emoji, hype caps, engagement bait, replying as a user, private names or paths
CTA: the release link or the command
Proof: the version, the command, the number with its source
Locales: English primary
