01 / できること

## できること

毎日の記録検索、アナリティクス、順位、クロールのデータを、増えていくだけの記録として保管します。

損失を見つけるどのサイト、国、クエリのグループ、ページがトラフィックを失っているか、その周りで何が変わったかを示します。

すべての行に計測の裏づけ各推奨には根拠となった数字が付いているので、確認できます。

### お客様のプロセスから始めます

エージェントに何をさせたいかをお知らせください。エージェントが引き受ける仕事、必要なシステム、誰が何を承認するかを確認します。

02

### エンジニアエージェントが組み立てます

合うテンプレートを選び、お客様が許可したアクセス権でシステムをつなぎ、ルールと支出の上限を設定します。

03

### 選んだ場所で動きます

お客様のマシンまたは自社クラウドで、お客様のキーを使って動きます。各エージェントは状態と支出を表示し、人の判断が必要なことは人が承認します。
