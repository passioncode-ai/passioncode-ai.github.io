## So verbindet sich jeder Agent

Jeder der folgenden Agenten kann die Tools von Switchboard nutzen: Er sieht, welcher Account seine Anfragen bearbeitet und wie viel Kontingent noch übrig ist, und er kann den Account wechseln. Agenten, die einen eigenen Endpoint akzeptieren, können ihre Anfragen außerdem über Switchboard senden, das für sie den Account wechselt. Einige lassen sich direkt aus Switchboard starten.

Nur Tools. Der Agent verbindet sich mit den Tools von Switchboard; seine Anfragen gehen an seinen eigenen Dienst.

Über Switchboard. Einmal im Agenten einrichten; Switchboard gibt die genauen Zeilen aus.

Start aus Switchboard. Switchboard startet den Agenten in einem Projektordner, mit den Accounts dieses Ordners.

Abo-Anmeldungen bleiben bei Claude Code und Codex, wie Anthropic und OpenAI es verlangen. Andere Agenten nutzen Accounts mit API-Schlüssel. Die Accounts eines Projekts dienen nur den Ordnern dieses Projekts.
