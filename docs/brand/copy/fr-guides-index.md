# Guides pour travailler avec des agents

De courts guides pour installer les outils sur votre ordinateur et faire entrer des agents dans votre organisation

Chaque guide explique ce qui se passe à chaque étape, avant que vous ne la franchissiez. Ils s’adressent à deux types de lecteurs : ceux qui installent les outils sur leur propre ordinateur, et les dirigeants qui font entrer des agents dans une entreprise.

## Par où commencer

Sur votre propre ordinateur : lisez d’abord le guide d’installation, puis lancez la commande de la page « Commencer ».

Pour votre entreprise : lisez comment fonctionne l’évaluation gratuite d’une semaine, puis comment les modèles d’agents deviennent vos agents.

### Comment fonctionne l’évaluation gratuite d’une semaine

Pendant une semaine, un agent lit le fonctionnement de votre entreprise, avec un accès en lecture seule. À la fin, vous obtenez une carte du déroulement réel du travail et une offre prête pour ce que les agents devraient reprendre en premier.

Pour les fondateurs qui veulent voir comment leur entreprise fonctionne vraiment avant de décider ce que prendront les agents.
