# AIネイティブな組織とは

AIネイティブな組織とは、エージェントがプロセスを動かし、人が舵を取る会社です。

Sergey Sheleg（PassionCode.ai 共同創業者）

## 仕事はエージェントの間を移る

今は、人がタスクを受け取り、抱え、次へ渡し、全員の成果を会議でまとめています。AIネイティブな会社では、エージェントがタスクを受け取って次のエージェントに渡し、エージェント同士が一つのボードで、記録とともにそれを解決します。

## 人に残るもの

方向：何を、なぜ作るか。目標、優先順位、そしてセンス。

管理：支払い、実際のユーザーへのリリース、社外の人へのメッセージなど、人の判断が必要なことの承認。

専門知識：市場と仕事の勘所を知り、あるべきやり方で仕事をするようエージェントに教えること。

## 多くのアシスタントではなく、一つのシステム

誰もがばらばらに作るエージェントの混乱は、すべてのエージェントが一つのコントラクト、キーのための一つの保管庫、そして何をしていくら使ったかの一つの記録を共有したときに終わります。何百ものエージェントのタスクを人が追うことはできませんが、一つのエージェントにはできます。Fabric は、エージェント同士が仕事を依頼し合うボードを持ちます。ボードの管理、仕事の振り分け、担当者を起こす機能は、現在プレビュー段階です。

## そうではないもの

一人に一つのアシスタントを付けることでも、人のいない会社でもありません。仕事はエージェントが担い、人はその仕事が何のためにあるかを決め、人の判断が必要なことを承認します。監視でもありません。分析の対象はエージェントとプロセスの成果であり、人を順位付けすることはありません。

## エージェントとデータの置き場所

組織自身のマシンまたは自社クラウドに、組織自身のキーとともに置かれます。各エージェントは何をしていて何に費用を使っているかを示すので、財務とエンジニアリングは、エージェントにかかった費用と成果を一つの記録で確認できます。

## 始め方

まずは1台のマシンから：コマンド1つでツールを無料でセットアップできます。会社の場合は、いまの仕事の進め方を見ることから始まり、最初のエージェントは次をもとに組み立てます：私たちのエージェントテンプレート。1週間の無料診断の進め方。
