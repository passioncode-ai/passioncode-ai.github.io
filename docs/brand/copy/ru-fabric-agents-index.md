Состояние на 14 октября 2026 года · последний релиз — Fabric 0.3.5

В последнем релизе Fabric подключает Claude Code, Codex, Kilo Code, Hermes Agent и Kimi Code: запускает агента в терминале проекта и даёт ему инструменты Fabric на эту сессию. ПОДКЛЮЧЁН

### Запускается с инструментами Fabric

Fabric запускает агента в терминале проекта. Только на эту сессию агент получает инструменты Fabric: взятие задач в работу, передачу работы, память и доску. Доступ выдаётся по ключу, который действует одну сессию, а в настройки самого агента ничего не записывается.

05 / КАК ПОДКЛЮЧАЮТСЯ ЗАПЛАНИРОВАННЫЕ АГЕНТЫ

## Один открытый протокол

## для запланированных агентов

Запланированные агенты подключаются по протоколу Agent Client Protocol (ACP). Когда открывается сессия, протокол передаёт агенту её MCP-серверы, поэтому Fabric может управлять любым агентом, который его поддерживает.

## Выбраны по тому,

## чем пользуются люди

Мы выбирали по открытому рейтингу приложений OpenRouter на 5 октября 2026 года. В его ежедневном топ-30 пятнадцать позиций занимают агенты для программирования и среды, в которых работают агенты. Самая большая доля у Hermes Agent, подключённого с Fabric 0.3.2.
