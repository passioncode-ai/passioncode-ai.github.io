# Агенты для программирования,

# с которыми работает Fabric

Каких агентов Fabric может запустить в вашем проекте, какие из них получают собственные инструменты Fabric и какие на очереди

На 5 октября 2026 г. · выпущенное приложение — Fabric 0.3

В выпущенном приложении Fabric подключает Claude Code: запускает агента в терминале проекта и даёт ему инструменты Fabric на эту сессию. Kilo Code и Hermes Agent подключены в разработке и выйдут в следующем релизе. Codex работает в Fabric, но инструментов Fabric у него пока нет. Первый из запланированных агентов — Cline, за ним остальные из списка ниже. Fabric Switchboard переключает аккаунты по подписке для Claude Code и Codex, а для остальных агентов — аккаунты с ключами API через Switchboard.

ПОДКЛЮЧЁН

### Запускается с инструментами Fabric

Fabric запускает агента в терминале проекта. Только на эту сессию агент получает собственные инструменты Fabric: захват задач, передачу, память и доску. Доступ даёт ключ на одну сессию, и в собственные настройки агента ничего не записывается.

РАБОТАЕТ В FABRIC

### Запускается в папке проекта

Fabric запускает агента в папке проекта, так что он работает с файлами этого проекта. Инструментов Fabric у него пока нет.

05 / КАК ПОДКЛЮЧАЮТСЯ ЗАПЛАНИРОВАННЫЕ АГЕНТЫ

## Один открытый протокол

## для запланированных агентов

Запланированные агенты подключаются по протоколу Agent Client Protocol (ACP). При настройке сессии он передаёт её MCP-серверы, и Fabric может управлять любым агентом, который его поддерживает.
