## Окно в

## инструменты, которые делают работу

Fabric Dashboards находит совместимые сервисы на вашем Mac. У каждого сервиса остаётся своя задача, а у вас появляется общее место, где можно следить за ними и управлять ими.

### Смотрите, что ждёт вас

Состояние сервиса, последняя активность и то, что требует внимания, показаны вместе. Медленный ответ на проверку не сразу считается сбоем.

### Открывайте настоящий дашборд

Собственный интерфейс каждого сервиса открывается прямо в приложении, уже с выполненным входом. Project Observatory — один из совместимых сервисов, которым можно пользоваться уже сегодня.

### Делайте следующий шаг

Запускайте, останавливайте и перезапускайте сервис, смотрите его логи и используйте действия, которые открывает его контракт. Если завершить Dashboards, сервисы продолжат работать.

Скачать Fabric Dashboards ↓

Откройте DMG, перетащите Fabric Dashboards в «Программы» и запустите. Приложение открывается при входе в систему; это можно изменить в настройках.

### Прежде чем открыть

Сервисы устанавливаются отдельно. Пока не установлен ни один совместимый сервис, пустой список — это нормально; Dashboards не превращает каждый локальный процесс в сервис агента.

Попробуйте Project Observatory или сделайте свой сервис с помощью Fabric Agent Adapter. Самому приложению не нужны ни аккаунт, ни ключ API.

03 / ДЛЯ ВАШИХ АГЕНТОВ

## Те же сервисы —

## из вашего агента

Зарегистрируйте MCP-сервер приложения в своём клиенте. Агент сможет получать список сервисов и ссылки на дашборды и выполнять операции, которые разрешают правила приложения.

claude mcp add --scope user fabric-dashboards -- "/Applications/Fabric Dashboards.app/Contents/Resources/bin/fabric-dashboards-mcp"

Установив приложение в «Программы», попросите агента вызвать list_services. Пустой результат означает, что ни один сервис ещё не установлен. Другие MCP-клиенты могут запускать тот же исполняемый файл как stdio-сервер. Подробнее — в руководстве по настройке MCP.

04 / ПОЛЕЗНО ЗНАТЬ

## Встраивается в ваше окружение

Нужен ли Fabric?

Нет. Fabric Dashboards работает сам по себе. Это один из инструментов Fabric, и он может показывать совместимые сервисы ещё до того, как вы начнёте пользоваться ранней предварительной версией Fabric.

Какие сервисы появляются?

Сервисы, которые публикуют локальный дескриптор для fabric-service/0.1. Project Observatory его поддерживает. Fabric Agent Contract задаёт протокол, а Adapter помогает его реализовать.

Это открытый код?

Fabric Dashboards — открытый код под GNU AGPL-3.0. Коммерческая лицензия доступна: passioncode.ai/business. Релиз 0.1.0 остаётся под MIT, 0.2.0 и 0.3.0 — под PolyForm Noncommercial или Internal Use. Релиз 0.3.1 — первый под AGPL.
