## 기능

업무를 지도로 그립니다작업의 종류, 각각에 걸리는 시간, 사람과 시스템 사이에서 일이 오가는 방식을 지도로 만듭니다.

대기 지점을 찾습니다일이 어디서 얼마나 멈추는지, 문서화된 프로세스가 실제와 어디서 다른지 보여 줍니다.

## 조직의 에이전트가 되기까지

템플릿에는 저희가 이런 종류의 에이전트를 운영하며 배운 것이 담겨 있습니다. 저희 엔지니어 에이전트가 조직에 맞춰 구성하며, 세부 내용은 요청 시 제공합니다.

01

### 조직의 프로세스에서 시작합니다

에이전트가 무엇을 해야 하는지 알려 주세요. 저희는 에이전트가 맡을 일, 필요한 시스템, 누가 무엇을 승인하는지 살펴봅니다.

02

### 저희 엔지니어 에이전트가 구성합니다

알맞은 템플릿을 골라, 허용하신 접근 권한으로 조직의 시스템을 연결하고, 조직의 규칙과 지출 한도를 설정합니다.

03

### 원하는 곳에서 실행됩니다

조직의 컴퓨터나 자체 클라우드에서, 조직의 키로 실행됩니다. 각 에이전트는 상태와 지출을 보여 주며, 사람이 필요한 일은 사람이 승인합니다.
