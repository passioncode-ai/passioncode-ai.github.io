# AIネイティブな組織についてのノート

企業がエージェントで動くようになる理由と、そのためのツールを作りながら学んでいること

ブログでは、ツールの背景にある考え方を説明します。エージェントが会社のプロセスを担い、人が方向を決めるとき、仕事がどう変わるのか。会社が AI とどう働くかを決める創業者とリーダーに向けて書いています。

Sergey Sheleg（PassionCode.ai 共同創業者）

## どこから始めるか

はじめての方は：まず「AIネイティブな組織とは」から読んでください。
