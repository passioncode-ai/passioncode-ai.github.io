01 / PASSIONCODE FOR ENTERPRISE

## 우리가 설정해 드리는 것

## 조직을 위해

PassionCode for Enterprise는 개발 중입니다. 파일럿은 오늘 오픈 소스 도구 위에서 진행되며, 에디션 자체는 요청 시 제공합니다.

컴퓨터가 조직에 합류합니다컴퓨터마다 에이전트, 계정, 규칙과 함께 한 번만 연결하면 됩니다.

에이전트 배포역할에 필요한 에이전트가 그 역할을 맡은 사람들의 컴퓨터에 전달됩니다.

컴퓨터 간 라우팅한 컴퓨터의 에이전트가 다른 컴퓨터의 에이전트에게 작업을 넘깁니다.

모델 접근은 로컬에 둡니다각 컴퓨터의 로컬 에이전트가 모델을 호출하므로, 키는 그것을 보관한 컴퓨터를 벗어나지 않습니다.

활동 및 사용 분석무엇이 어떤 프로세스에서 실행되었고, 무엇을 사용했고, 비용이 얼마였는지 보여 줍니다.

관리각 에이전트가 무엇을 할 수 있고 어떤 계정과 데이터에 접근할 수 있는지를 조직 전체에 한 번만 설정합니다.

우리가 서명하는 맞춤 빌드PassionCode.ai가 서명한, 조직 전용 도구 빌드입니다.

데이터는 조직의 컴퓨터나 자체 클라우드에 남습니다. 비전 읽기

## 문의 전에

비용은 얼마인가요?

도구는 무료이며 오픈 소스입니다. 비용은 저희가 해 드리는 작업(프로세스 정리, 구축, 호스팅, 지원)과, 필요한 경우 상용 라이선스에 대해서만 발생합니다. 가격은 프로세스를 파악한 뒤 제안서에 명시하며, 정해진 패키지는 없습니다.

상용 라이선스는 언제 필요한가요?

도구는 GNU AGPL-3.0을 따릅니다. 내부 사용과 같은 라이선스로 공개하는 변경 사항에는 아무것도 필요하지 않습니다. 도구를 포함한 비공개 제품이나, 소스를 공개하지 않는 수정된 호스팅 서비스에는 상용 라이선스가 필요합니다.
