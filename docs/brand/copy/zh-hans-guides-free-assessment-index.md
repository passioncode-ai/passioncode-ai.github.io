# 为期一周的免费评估如何进行

一个智能体以只读权限用一周时间了解你公司的运作方式。结束时，你会得到一张展示工作实际如何运行的地图，以及一份现成的方案，说明哪些工作应最先交给智能体。

Sergey Sheleg，PassionCode.ai 联合创始人

应需提供

## 这一周开始之前

你回答四个问题：你的目标、团队规模、使用的系统，以及最让你头疼的是什么。你为这些系统提供只读权限，每个系统一个链接。我们的工程师智能体会在为你的组织单独设立的空间里部署评估智能体；如果数据不应离开你的机器，则部署在你自己的机器上。这大约占用你二十分钟时间。

## 这一周期间

智能体连接你的任务跟踪工具、代码仓库、文档、团队聊天、邮件和客服系统，读取最近 90 天的数据。之后它会实时跟进工作：计划了什么、实际发生了什么、工作在哪里等待、等了多久。如果数据有缺口，它可能会在你的团队已经在用的渠道里问几个简短的问题，默认匿名。你的系统不会发生任何变化。

## 第七天你会得到什么

一张流程地图：有哪些类型的任务、每类耗费多少时间，以及工作如何在人和系统之间流转。

计划与实际的对比、阻碍和等待，以及书面流程与实际流程的差异所在。

方案：应最先交给智能体的流程、每个流程能腾出的小时数、承担这项工作的智能体模板，以及在一个流程上开展的验证试点。

我们会在 30 分钟的通话中和你一起过一遍，你可以把它作为一个页面保留下来。

## 关于人：绝不打分

评估针对的是流程，而不是人。它报告的是群体的汇总数据，绝不给个人打分；留给人的部分（方向、控制和专业能力）也是方案的一部分。

## 这一周之后

如果你决定继续，试点会在同一个地方开始。如果不继续，访问权限会被撤销，数据会被删除，你会收到删除完成的确认。
