# 組織管理者エージェント

人がすでに会話している場所で、チームのリズムを保ちます：朝のリスト、滞っているタスク、ブロッカー、そして適切な担当者に振り分けられる依頼。

01 / できること

## できること

リズムを保つ朝のリストを送り、勤務時間内に緊急のタスクや滞っているタスクを担当者に知らせ、ブロッカーの一覧を管理します。

依頼を振り分ける誰かが持ち込んだ問題を受け取り、その担当の人またはエージェントに渡します。

名簿を管理する入社と退社をそれぞれ1つのチェックリストで進め、その人に組織のエージェントへのアクセスを付与します。

02 / 対象

## 対象

進捗の確認や、誰が何の担当かの問い合わせに時間を取られているチームのために。

### 得られるもの

進捗確認の会議が減る

すべての依頼に担当者

常に最新のチーム名簿

## 自社のエージェントになるまで

01

### お客様のプロセスから始めます

エージェントに何をさせたいかをお知らせください。エージェントが引き受ける仕事、必要なシステム、誰が何を承認するかを確認します。

02

### エンジニアエージェントが組み立てます

合うテンプレートを選び、お客様が許可したアクセス権でシステムをつなぎ、ルールと支出の上限を設定します。

03

### 選んだ場所で動きます

お客様のマシンまたは自社クラウドで、お客様のキーを使って動きます。各エージェントは状態と支出を表示し、人の判断が必要なことは人が承認します。
