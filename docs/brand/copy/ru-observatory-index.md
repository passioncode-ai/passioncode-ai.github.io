## Больше подтверждений с одного взгляда

01 / РЕЕСТР

### Узнайте, что у вас есть

Выберите папку с проектами, за которой хотите наблюдать. Observatory найдёт в ней репозитории и ведёт локальный реестр, где у каждой связи указано правило, по которому она установлена.

02 / АКТИВНОСТЬ

### Смотрите, что изменилось

Коммиты, состояние рабочего дерева и работа, которая есть только на этой машине, по всем отслеживаемым проектам, а для каждого ещё и разбивка по неделям.

03 / НАХОДКИ

### Начинайте с важного

У каждой находки есть подтверждения и следующий шаг, а порядок идёт от «критично» до «к сведению». У заглушённой находки записано, кто её заглушил, когда и почему.

04 / КЛЮЧИ

### Находите копии известных ключей

Сведения о ключах хранятся отдельно от их значений. Выбранные транскрипты, логи и базы SQLite сверяются с ключами, которые уже известны на этой машине; в находках значение ключа никогда не повторяется.

05 / ВАШ ЯЗЫК

### Английский или русский

По умолчанию дашборд на английском. Включите русский для рабочего пространства или переключайтесь кнопкой EN/RU на боковой панели; числа согласуются со словами по правилам каждого языка.

06 / АГЕНТЫ

### Дайте следующему агенту контекст

CLI, инструменты MCP и плагин для Claude Code опираются на одни и те же локальные факты. Интеграции и фоновые задачи выключены, пока вы сами их не включите.

СКАЧАТЬ OBSERVATORY

## Начните со своего рабочего пространства

Последний релиз: 0.24.4. Для первого локального наблюдения ключ API не нужен. Поручите установку своему агенту для программирования или установите всё сами.

01

### Установите релиз

Скачать project_observatory-0.24.4-py3-none-any.whl и SHA256SUMS из релиза 0.24.4, проверить их командой shasum -a 256 -c SHA256SUMS --ignore-missing, затем в изолированном окружении Python 3.11+ с поддержкой расширений SQLite выполнить pip install --no-deps для wheel, а потом для его дополнения [full] с -c "$(project-observatory full-path)/requirements-full.lock" — это набор зависимостей, с которым релиз тестировался. На macOS используйте Python из Homebrew. На Windows — Python 3.13 или новее и шаги для PowerShell из руководства по установке.

02

### Создайте личное рабочее пространство

project-observatory full init, затем выберите папку для наблюдения командой full configure sources projects. Конфигурация, ключи и история хранятся отдельно от установленного кода.

03

### Запустите наблюдение и откройте дашборд

project-observatory full local, затем full open. Для русского языка: full configure interface locale ru.

04

### Подключите агента

MCP-сервер работает через stdio: claude mcp add observatory --scope user -e OBSERVATORY_HOME="$OBSERVATORY_HOME" -- "$(python -c 'import sys; print(sys.executable)')" "$(project-observatory full-path)/mcp/server.py", затем попросите агента вызвать observatory_overview.

Приложение для Mac: ProjectObservatory-0.24.4-macos.zip, одно приложение для Apple silicon и Intel под macOS 14+; оно подписано Developer ID и нотаризовано Apple. Приложение открывается на дашборде и работает с движком, установленным выше; проверьте его по тому же SHA256SUMS.

Приложение для Windows и Linux (с версии 0.22.0): установщик для Windows x64 и arm64 с подписью Authenticode, которому не нужны права администратора, а также AppImage и .deb для Linux x64 и arm64 — на странице релиза 0.24.4. Как и приложение для Mac, оно открывается на дашборде и работает только с движком, установленным выше: само оно движок не устанавливает. Обновляется приложение само, кроме копии из .deb: для неё установите следующий .deb.

Текущий релиз, 0.24.4, выпущен под AGPL, как и все релизы начиная с 0.10.0 — первого под AGPL; 0.9.1 и более ранние сохраняют лицензию, с которой вышли.

Поиск по известным значениям сверяет выбранные артефакты с ключами, которые уже известны на этой машине. Он не может найти неизвестные секреты или доказать, что копий не осталось, а локальная копия ещё не значит, что ключ попал к кому-то ещё. Офлайн-тесты не проверяют ротацию ключей у реальных провайдеров и внешние MCP-хосты.

## Что важно различать

Observatory куда-то отправляет мои проекты или ключи?

Нет. Реестр, история и наблюдения хранятся в вашем личном рабочем пространстве на вашей машине. У необязательных интеграций свой доступ: каждую вы включаете отдельно, под своим аккаунтом.

Что читает Observatory?

Только те папки и источники, которые вы настроили. full doctor показывает, что включено и чего не хватает, а если источник не измерялся, дашборд так и пишет, а не показывает ноль.

Это то же самое, что Switchboard?

Нет. Switchboard управляет вашими аккаунтами Claude Code и Codex. Observatory держит на виду проекты, над которыми работают эти агенты. Оба — инструменты PassionCode с открытым кодом, которыми можно пользоваться уже сегодня.

А Fabric?

Fabric — дом для ваших проектов и их агентов, пока в ранней предварительной версии. Observatory доступен уже сейчас как отдельный локальный инструмент. Подробнее о Fabric.

Можно ли изучить код или собрать Observatory самому?

Да. Project Observatory — открытый код под GNU AGPL-3.0. Для использования, которое AGPL не покрывает, коммерческую лицензию можно получить на passioncode.ai/business. Выпущенные версии сохраняют свою лицензию: 0.8.1 и более ранние — MIT, с 0.8.2 по 0.9.1 — PolyForm Noncommercial или Internal Use. В репозитории есть исходный код, тесты, модель безопасности и заметки к релизам.
