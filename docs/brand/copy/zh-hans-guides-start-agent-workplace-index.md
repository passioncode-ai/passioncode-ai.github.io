# 20 分钟搭建你的智能体工作空间

在你自己的电脑上安装这些工具时，每一步会发生什么：从那一条命令，到你的第一个智能体和下一个智能体。

Sergey Sheleg，PassionCode.ai 联合创始人

## 你需要什么

一台装有 Node.js 18 或更新版本的电脑，以及 Claude Code 或 Codex。Fabric 是你的项目及其智能体的家，目前处于早期预览阶段，在所有系统上还需要 Docker 和 Supabase CLI。所有工具都是开源的，个人使用免费。

## 运行一条命令

在 macOS 上，一条命令会从签名版本中安装你选择的工具，把它们的 MCP 服务器连接到你的编码智能体，并添加技能。在 Windows 和 Linux 上，请先从各应用的页面下载应用，再运行同一条命令来安装技能和 MCP 服务器。签名或校验和未通过的内容一概不安装。你也可以把这项工作交给你的编码智能体：命令和给编码智能体的提示词都在“开始使用”页面上。

## 重启你的编码智能体并检查

重启 Claude Code 或 Codex，让它加载新工具。再次运行同一条命令，或运行 doctor 只做检查、不做任何更改：它会告诉你哪些已经装好、缺少什么，以及只有你能完成的步骤，比如登录。

## 创建或适配你的第一个智能体

用平实的话向你的编码智能体说出你的需求，或从 Fabric 的创建和适配操作开始。Fabric Agent Adapter 技能会先提出问题，并在做任何更改之前展示它的计划。你会得到一个带有契约、仪表盘和测试的智能体。

## 看它运行

Fabric Dashboards 在一个窗口中显示所有本地智能体服务：它们在做什么、花费多少。你的编码智能体可以替你启动、停止和打开它们。

## 把下一个智能体加入同一个项目

以同样的方式构建下一个智能体，并让它加入 Fabric 中的同一个项目。连接到 Fabric 的智能体共用一个项目的看板、记忆和交接，因此一个智能体可以从另一个停下的地方接着做。

## 如果出了问题

再运行一次这条命令：在已经安装好的电脑上，它会检查所有内容，修复出错的部分，并显示改动了什么。每个产品页面都列出了它的要求和限制。
