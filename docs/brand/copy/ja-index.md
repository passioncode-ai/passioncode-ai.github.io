01 / 理由

## 1週間は動きます

## そして、破綻します

間違ったアカウントで動いたり、上限に達したりします。昨日学んだことを忘れ、何を変えたのか誰にも説明できません。次に作るエージェントは、またゼロから始まります。

お使いのマシンで、オープンソースとしてPassionCode.ai は、AIエージェントと働くためのローカルなワークスペースで、GNU AGPL-3.0 のオープンソースです。お使いのマシン上で動き、登録は不要で、ロックインもありません。

お手持ちのエージェントとともにClaude Code や Codex、そしてその先のツールを、すでにお持ちのサブスクリプションでお使いいただけます。

開いて確かめられる記録プロジェクトのボードには、決定事項、タスク、リリースが残ります。Observatory は、何が変わったかを証跡と次のステップとともに一覧にします。すべてのダウンロードに、バージョンと SHA-256 が記載されています。

ビジョンを読む：エージェントが働き続けるために必要なものと、1つのエージェントが組織へと育つ道筋

06 / よくある質問

## よくあるご質問

PassionCode.ai は無料ですか？

はい。すべてのツールは GNU AGPL-3.0 のオープンソースで、無料でダウンロード、利用、調査、変更できます。クローズドな製品に組み込む場合や、変更したホスト型サービスをソースを公開せずに運用する場合には、商用ライセンスをご利用いただけます。

どのエージェントに対応していますか？

特定のエージェントに依存しません。現在 Claude Code、Codex、Kilo Code、Hermes Agent、Kimi Code が Fabric に接続でき、Cline は Fabric の中で動作します。今後も対応を増やす予定です：レベル別の一覧。

データはどこに送られますか？

作業内容はお使いのコンピュータと、ご自身のクラウドアカウントの中に留まります。Fabric Switchboard と、バージョン 0.3.2 以降の Fabric は、匿名の利用回数を送信します。送るのは回数と種類のみで、名前、パス、内容は送りません。Switchboard の「About」ウィンドウ、または Fabric の設定でオフにできます。送信される内容の詳細。

## ここに至るまで

Sergey Shelegです。インストール数が5,700万回を超える代替Telegramクライアント「Nicegram」の共同創業者兼CPOで、eSIM Plusの共同創業者でもあります。以前はUltimate GuitarでAndroidとグロースプロダクトを率いていました。同社のアプリは3億5,000万人以上に届いています。プロダクト、グロース、マーケティング、AI、ブロックチェーンにまたがって仕事をしています。

PassionCodeのもう一人の共同創業者はSerge Khursです。Teslasuitの共同創業者兼CTOです。Teslasuitは、ハプティクス、筋肉への電気刺激、センサー、モーショントラッキングを備えた全身スーツで、医療、トレーニング、産業、防衛の分野で使われています。現在はAIとバックエンドシステムのエンジニアとして、大手の国際的なデジタル企業に助言しています。

私たちはどちらもチームを率いていて、始まりも同じでした。エージェントのための自分のワークプレースを整えることです。試行錯誤しながらワークプレースのあるべき形を見つけ、技術とプロダクトの長年の経験を生かして、社内のプロセスを磨き続けました。

やがてそれは、AIネイティブなエージェントチームのための仕組みになりました。ワークプレースの姿、エージェントのシステムの組み立て方、そしてそれを組織にどう組み込むかです。毎回同じように動くようソフトウェアにまとめ、今では私たち自身の仕事がその上で動いています。

その後、これは私たち二人だけでなく、もっと多くの人の役に立つと気づきました。開発、マーケティング、財務、広告、あるいは自動化できるあらゆる定型業務で、AIエージェントと仕事をするすべての人です。ソフトウェアは仕事に合わせて変えられるので、オープンソースにしました。インストールして、ワークプレースを自分に合わせ、エージェント中心にして、Claude Codeを本来の使い方で使ってください。

私たちのチームでは、同じ問題を何度も目にしました。タスクの一部をチャットに任せ、その結果を人に戻すだけで、プロセスは変わらないままです。変えるべきなのはプロセスそのものです。

それこそが、私たちが組織に向けて行っていることです。実際の業務プロセスの定型作業をエージェントに任せたい場合は、PassionCodeをお客様のシステムにつなぎ、そのプロセスを担うカスタムエージェントの導入を支援します。プロセスについて教えてください →
