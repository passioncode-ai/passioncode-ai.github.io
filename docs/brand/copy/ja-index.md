01 / 理由

## ハーネスがなければ、

## エージェントは傷んでいく

アカウントはバラバラで、セッションをまたぐとすべてを忘れ、何をしたかの証跡も残さず、互いに話すこともありません。

エージェントの拠点PassionCode.ai は、AIエージェントと働くためのローカルのオープンソース・ワークスペースです。各エージェントに、拠点、アカウント、状態管理、メモリ、証跡を用意します。

お使いのツールの上でClaude Code や Codex、そしてその先のツールを、すでにお持ちのサブスクリプションでお使いいただけます。

すべてがあなたのものGNU AGPL-3.0 のオープンソースで、お使いのマシンとアカウント上で動きます。登録は不要で、ロックインもありません。

05 / よくある質問

## よくあるご質問

PassionCode.ai は無料ですか？

はい。すべてのツールは GNU AGPL-3.0 のオープンソースで、無料でダウンロード、利用、調査、変更できます。クローズドな製品に組み込む場合や、変更したホスト型サービスをソースを公開せずに運用する場合には、商用ライセンスをご利用いただけます。

どのエージェントに対応していますか？

特定のエージェントに依存しません。現在 Claude Code、Kilo Code、Hermes Agent が Fabric に接続でき、Codex と Cline は Fabric の中で動作します。今後も対応を増やす予定です：レベル別の一覧。

データはどこに送られますか？

作業内容はお使いのコンピュータと、ご自身のクラウドアカウントの中に留まります。Fabric Switchboard と、バージョン 0.3.2 以降の Fabric は、匿名の利用回数を送信します。送るのは回数と種類のみで、名前、パス、内容は送りません。Switchboard の「About」ウィンドウ、または Fabric の設定でオフにできます。送信される内容の詳細。
