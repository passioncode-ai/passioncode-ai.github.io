07 / ご質問

## よくあるご質問

PassionCode.ai は無料ですか？

はい。すべてのツールは GNU AGPL-3.0 のオープンソースで、無料でダウンロード、利用、調査、変更できます。クローズドな製品に組み込む場合や、変更したホスト型サービスをソースを公開せずに運用する場合には、商用ライセンスをご利用いただけます。

どのエージェントに対応していますか？

特定のエージェントに依存しません。現在 Claude Code、Kilo Code、Hermes Agent が Fabric に接続でき、Codex と Cline は Fabric の中で動作します。今後も対応を増やす予定です：レベル別の一覧。あらゆるエージェント、MCP サーバー、コマンドラインツールを Fabric Agent Adapter で Fabric 互換のサービスにできます。

既存のプロジェクトやエージェントを Fabric エージェントにするには？

PassionCode.ai ランチャーをインストールし（npx @passioncode-ai/passioncode@latest update）、コーディングエージェントにプロジェクトを Fabric に適合させるよう依頼します。Fabric Agent Adapter スキルが、コントラクト、ダッシュボード、適合性チェックを備えたサービスとして包みます。ガイドで手順を確認できます。

Fabric は自分でエージェントを作りますか？

まだです。Fabric は早期プレビュー版で、各プロジェクトのボード、決定事項、リリースを管理しますが、会話にはまだ返信できません。会話からエージェントを作ることが目指す方向で、現時点ではコーディングエージェントが Fabric Agent Adapter スキルで行います。

データはどこに送られますか？

作業内容はお使いのコンピュータと、ご自身のクラウドアカウントの中に留まります。Fabric Switchboard と、バージョン 0.3.2 以降の Fabric は、匿名の利用回数を送信します。送るのは回数と種類のみで、名前、パス、内容は送りません。Switchboard の「About」ウィンドウ、または Fabric の設定でオフにできます。送信される内容の詳細。

PassionCode.ai で自社向けにセットアップしてもらえますか？

はい。チームとプロセスをお知らせいただければ、見積もりと提案をお返しします：ガイド付きオンボーディング、または私たちが構築・運用するワークプレース。
