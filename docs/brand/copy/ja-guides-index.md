# エージェントと働くためのガイド

コンピューターへのツールのセットアップと、組織へのエージェント導入についての短いガイド

各ガイドは、手を動かす前に、それぞれのステップで何が起きるかを説明します。自分のコンピューターにツールをセットアップする人と、会社にエージェントを導入するリーダーのためのガイドです。

## どこから始めるか

自分のコンピューターで：まずセットアップのガイドを読み、次に「はじめる」ページのコマンドを実行してください。

会社で：まず1週間の無料診断の進め方を読み、次にエージェントテンプレートが自社のエージェントになるまでを読んでください。

### 1週間の無料診断の進め方

1つのエージェントが、読み取り専用のアクセスで1週間、会社の仕事の進め方を読み取ります。最後に、仕事が実際にどう動いているかの地図と、最初にエージェントに任せるべき仕事についての具体的な提案をお渡しします。

エージェントに任せる仕事を決める前に、会社が実際にどう動いているかを知りたい創業者へ。
