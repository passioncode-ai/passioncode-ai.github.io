# Lancez votre espace de travail pour agents en 20 minutes

Ce qui se passe à chaque étape de l’installation des outils sur votre propre ordinateur, de la commande unique à votre premier agent et au suivant.

Sergey Sheleg, cofondateur de PassionCode.ai

## Ce qu’il vous faut

Un ordinateur avec Node.js 18 ou version ultérieure, et Claude Code ou Codex. Fabric, le foyer de vos projets et de leurs agents, est en préversion et nécessite aussi Docker et Supabase CLI sur tous les systèmes. Tout est open source et gratuit pour un usage personnel.

## Lancez une commande

Sur macOS, une commande installe les outils que vous choisissez à partir de leurs versions signées, connecte leurs serveurs MCP à votre agent de code et ajoute les skills. Sous Windows et Linux, téléchargez d’abord les applications depuis leurs pages, puis lancez la même commande pour les skills et les serveurs MCP. Elle n’installe rien dont la signature ou la somme de contrôle échoue. Vous pouvez aussi confier la tâche à votre agent de code : la commande et un prompt pour votre agent de code se trouvent sur la page Premiers pas.

## Redémarrez votre agent de code et vérifiez

Redémarrez Claude Code ou Codex pour qu’il prenne en compte les nouveaux outils. Relancez la même commande, ou doctor pour vérifier sans rien modifier : il vous indique ce qui est en place, ce qui manque et les étapes que vous seul pouvez accomplir, comme vous connecter.

## Créez ou adaptez votre premier agent

Demandez à votre agent de code ce dont vous avez besoin, avec des mots simples, ou partez des actions Créer et Adapter de Fabric. Le skill Fabric Agent Adapter pose d’abord ses questions et montre son plan avant de modifier quoi que ce soit. Vous obtenez un agent avec un contrat, un tableau de bord et des tests.

## Regardez-le tourner

Fabric Dashboards affiche tous les services d’agents locaux dans une seule fenêtre : ce que chacun fait et ce qu’il dépense. Votre agent de code peut les démarrer, les arrêter et les ouvrir pour vous.

## Ajoutez l’agent suivant au même projet

Construisez le prochain agent de la même façon et donnez-lui le même projet dans Fabric. Les agents connectés à Fabric partagent le tableau, la mémoire et les passations d’un même projet : l’un reprend là où l’autre s’est arrêté.

## Si quelque chose ne fonctionne pas

Relancez la commande : sur un ordinateur déjà installé, elle vérifie tout, répare ce qui ne va pas et montre ce qui a changé. Chaque page produit indique ses prérequis et ses limites.
