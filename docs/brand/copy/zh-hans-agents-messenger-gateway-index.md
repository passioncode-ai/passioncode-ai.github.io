01 / 它能做什么

## 它能做什么

身份统一存放即时通讯账号和机器人都放在一个服务里，其他智能体都不持有它们。

按智能体分配权限每个智能体只获得它需要的权限：读取、搜索、发送或管理群组。

发送由人批准除非所有者设定了长期规则，否则消息会等待人的批准。

02 / 适合谁

## 适合谁

适合智能体在 Telegram 上与人沟通、且不应各自持有账号的组织。

### 你会得到什么

机器人令牌不再散落在各个项目中

每条已发送消息都有记录

一个开关即可停止所有发送

03 / 如何组装

## 模板如何

## 变成你的智能体

模板汇集了我们运行这类智能体积累的经验。我们的工程师智能体会为你的组织组装它；详情应需提供。

01

### 我们从你的流程出发

你告诉我们智能体应该做什么。我们会了解它接手的工作、它需要的系统，以及谁来批准什么。

02

### 由我们的工程师智能体组装

它选取合适的模板，以你授予的权限连接你的系统，并设置你的规则和支出上限。

03

### 在你选择的地方运行

运行在你的机器或你自己的云上，使用你的密钥。每个智能体都会显示其状态和花费，必须由人处理的事项由人批准。
