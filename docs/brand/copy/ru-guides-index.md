# Руководства по работе с агентами

Короткие руководства по настройке инструментов на вашем компьютере и по внедрению агентов в вашу организацию

Каждое руководство объясняет, что происходит на каждом шаге, ещё до того, как вы его сделаете. Они для двух типов читателей: тех, кто настраивает инструменты на своём компьютере, и руководителей, которые внедряют агентов в компании.

## С чего начать

На своём компьютере: сначала прочитайте руководство по настройке, затем выполните команду со страницы «Начать».

Для вашей компании: прочитайте, как проходит бесплатная оценка за неделю, а затем как шаблоны агентов становятся вашими агентами.

### Как проходит бесплатная оценка за неделю

Один агент неделю изучает, как работает ваша компания, с доступом только на чтение. В конце вы получаете карту того, как на самом деле идёт работа, и готовое предложение: что агентам стоит взять на себя в первую очередь.
