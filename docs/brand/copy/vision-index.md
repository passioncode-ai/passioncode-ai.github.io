01 / WHAT HOLDS AN AGENT

## The model is not the problem

## What holds it is

Most organizations already experiment with agents, yet no more than 10% scale them in any one function. An agent built alone forgets between sessions and loses track of its accounts. It leaves no record of what it did, and the next agent knows nothing about it. We call what holds it together a harness: everything around a model that keeps an agent working over time. The labs use the word too: Anthropic, OpenAI.

01

### A home

Each project has one place for its purpose, board, decisions and releases, shared by every agent that works on it. That is Fabric.

02

### Accounts

Each agent runs on the account it should, with its limits in view. That is Fabric Switchboard.

03

### State and control

Every agent service, what it is doing and what it spends, in one window that people and agents can drive. That is Fabric Dashboards.

04

### Memory and evidence

What changed, what was decided and what needs attention, with the proof beside it. That is Project Observatory.

02 / WHAT WE BELIEVE

## Four principles

## we build by

Projects are the axisEvery agent works for a project, and the project keeps the purpose, decisions and releases, so the work outlives the session that did it.

The work improves itselfA run leaves evidence you can open, and Observatory keeps it today. Retrospectives that turn it into lessons the next agent learns from are the direction.

Any agent, on your machinesVendor-neutral, local first and open source under the GNU AGPL-3.0, on top of Claude Code, Codex and what comes next.

Analytics, never surveillanceAnalytics are about agents and the outcomes of processes. Nothing watches people in secret.

Inside each change we recommend task-pipeline, a separate open-source skill that does not move on until each gate passes. How to install it
