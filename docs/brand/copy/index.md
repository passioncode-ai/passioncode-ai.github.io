07 / QUESTIONS

## Questions people ask first

Is PassionCode.ai free?

Yes. Every tool is open source under the GNU AGPL-3.0: you can download, use, study and change it at no cost. A commercial license is available when you ship it inside a closed product or run a modified hosted service without publishing its source.

Which agents does it work with?

It is agent-agnostic. Claude Code, Kilo Code and Hermes Agent connect to Fabric today, Codex and Cline run inside it, and more are planned: the full list, by level. Any agent, MCP server or command-line tool can become a Fabric-compatible service with the Fabric Agent Adapter.

How do I turn an existing project or agent into a Fabric agent?

Install the PassionCode.ai launcher (npx @passioncode-ai/passioncode@latest update), then ask your coding agent to adapt the project to Fabric. The Fabric Agent Adapter skill wraps it as a service with a contract, a dashboard and a conformance check. The guide shows the steps.

Does Fabric create agents by itself?

Not yet. Fabric is in early preview: it keeps each project’s board, decisions and releases, and its conversation does not reply yet. Creating agents from a conversation is the direction; today your coding agent does it with the Fabric Agent Adapter skill.

Where does my data go?

Your work stays on your computers and your own cloud accounts. Fabric Switchboard and, since version 0.3.2, Fabric send anonymous usage counts: counts and kinds only, never names, paths or content. Turn them off in Switchboard’s About window or in Fabric’s Settings. What is sent, exactly.

Can PassionCode.ai set this up for my company?

Yes. Describe your team and processes and we reply with an estimate and a proposal: guided onboarding, or a workplace we build and run for you.
