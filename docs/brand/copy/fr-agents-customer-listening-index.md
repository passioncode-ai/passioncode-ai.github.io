01 / CE QU’IL FAIT

## Ce qu’il fait

Une seule vue d’ensembleRéunit les avis des stores, les chats de support, la communauté et les mentions publiques dans une seule vue classée.

Des alertes dès que ça changePrévient les bonnes personnes quand un problème grandit ou qu’un nouveau risque apparaît.

La confidentialité d’abordConserve des résumés, des étiquettes et des comptages plutôt que les propres mots des gens là où les règles les interdisent.

02 / À QUI IL S’ADRESSE

## À qui il s’adresse

Pour les équipes qui veulent une seule vue de ce que disent les clients, sans lire chaque canal.

### Ce que vous obtenez

Une vue hebdomadaire de ce que disent les clients

Des problèmes classés selon le nombre de personnes qui les rencontrent

Des agents de réponse qui en tirent des leçons

03 / COMMENT IL EST ASSEMBLÉ

## Comment un modèle

## devient votre agent

Le modèle contient ce que nous avons appris en faisant tourner des agents de ce type. Notre agent ingénieur l’assemble pour votre organisation ; les détails sont fournis sur demande.

01

### Nous partons de vos processus

Vous nous dites ce que l’agent doit faire. Nous examinons le travail qu’il reprend, les systèmes dont il a besoin et qui approuve quoi.

02

### Notre agent ingénieur l’assemble

Il prend le modèle adapté, connecte vos systèmes avec les accès que vous accordez, et fixe vos règles et vos limites de dépenses.

03

### Il tourne là où vous le choisissez

Sur vos machines ou dans votre propre cloud, avec vos clés. Chaque agent affiche son état et ses dépenses, et une personne approuve ce qui demande une personne.
