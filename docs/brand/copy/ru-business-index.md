02 / ДЛЯ ФИНАНСОВ И РАЗРАБОТКИ

## Одна сводка: сколько стоили агенты

## и какой результат они дали

Финансы и разработка (CFO и CTO или CIO) смотрят на агентов с двух сторон: разработка хочет больше агентов, финансы хотят понимать, за что заплачен каждый доллар. Обе стороны задают один вопрос: сколько стоил каждый агент и какой результат он дал? Это и есть ROI каждого агента. Когда ответ лежит в одной записи, которую открывают обе стороны, решение добавить агента опирается на цифры.

{ "id": "a new random UUID v4: make it once, reuse it if you send again", "lang": "the language we talk in: en, ru, de, fr, es, pt-br, pl, ko, ja or zh-hans", "contact": { "email": "the work email", "message": "what agents should do, in my words, up to 4000 characters" }, "goals": ["one of: cost_and_results, automate_operations, custom_agents, convert_agents, commercial_license, managed_hosting, team_onboarding"], "company": { "size": "one of: 1_10, 11_50, 51_200, 201_1000, 1000_plus" }, "processes": { "tools": ["any of: claude_code, codex, cursor, chatgpt, other_agents, none"] }, "budget": { "timeline": "one of: asap, this_quarter, next_quarter, exploring" }, "source": { "channel": "agent-prompt", "agent": "your own name, such as Claude Code or Codex" } }

Получи токен формы, подожди четыре секунды, добавь токен в JSON как «form_token», сохрани как request.json и проверь заявку. Проверка ничего не сохраняет и не отправляет:

curl -s https://passioncode.ai/api/leads/token sleep 4 curl -s -X POST 'https://passioncode.ai/api/leads?dry_run=1' -H 'Content-Type: application/json' --data @request.json

curl -s -X POST https://passioncode.ai/api/leads -H 'Content-Type: application/json' --data @request.json

05 / ВОПРОСЫ

## Прежде чем спросить

Сколько это стоит?

Инструменты бесплатны, их код открыт. Вы платите за работу, которую мы делаем для вас (разбор процессов, разработку, хостинг и поддержку), и за коммерческую лицензию, если она нужна. Цену мы называем в предложении, когда разберёмся в ваших процессах; фиксированного пакета нет.

Когда нужна коммерческая лицензия?

Инструменты распространяются под GNU AGPL-3.0. Для внутреннего использования и для изменений, которые вы публикуете под той же лицензией, ничего не нужно. Коммерческая лицензия нужна, если инструменты входят в закрытый продукт или если вы запускаете изменённую версию как сервис и не публикуете её исходный код.

Это способ следить за людьми?

Нет. Аналитика — про агентов и процессы: сколько стоил каждый агент и какой результат он дал. Людей она не ранжирует.
