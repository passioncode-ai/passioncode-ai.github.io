## Проект живёт дольше,

## чем разговор

Агент может закончить задачу, а команда при этом потеряет, зачем она делалась. Контекст расползается по чатам, решения приходится повторять, и кому-то нужно заново собирать работу воедино.

Мы строим Fabric вокруг проекта: цели, команды, решений и истории, которые должны пережить следующую сессию.

## к проверенному результату

К такому рабочему процессу мы идём. Это направление развития Fabric, а не обещание, что каждый шаг доступен уже сегодня.

### Координировать выполнение

Распределять работу между людьми, агентами и повторяемыми процессами, не теряя контекст проекта.

04

### Проверять и учиться дальше

Сверять результат с подтверждениями. Сохранять решения и выводы для следующего цикла.

## Ответственность остаётся за людьми

Координация — то, куда движется Fabric, и она никогда не заменит вас. Зачем нужен проект и что разрешено каждому агенту, решаете вы.

ПОЛНОМОЧИЯ

### Разрешения остаются явными

Цели, обязанности и ограничения принадлежат проекту. Уверенность агента — не разрешение действовать.

ВЫБОР

### Агентов можно заменить

Проект должен сохранять цель и историю, когда вы меняете провайдера или агента, который делает работу.

ПОДТВЕРЖДЕНИЯ

### У результата должна быть квитанция

К выполненной задаче должно прилагаться то, что может проверить человек, а не только слова агента, что всё готово.

### Прежде чем открыть

Fabric запускает собственную локальную базу данных через Supabase CLI внутри Docker.

Запущенный Docker Desktop или OrbStack

Supabase CLI: brew install supabase/tap/supabase

Claude Code или Codex CLI с выполненным входом — чтобы агенты могли работать

Если Docker или CLI не установлены, при первом запуске Fabric скажет, чего не хватает. Посмотрите, с какими агентами для программирования работает Fabric и что каждый из них может в нём делать.

Это ранняя предварительная версия. В ней можно вести проекты, доску решений, задачи, цели, пульс работы и релизы с квитанциями. Чат с Fabric сохраняет ваши сообщения, но Fabric пока не отвечает. Новая версия не обновляет существующую базу данных сама — она подскажет, какую команду выполнить. Агенты, зарегистрированные на этом Mac, могут через локальный хаб агентов Fabric запросить доступ к подключённому продукту, например к Fabric Inbox; вы разрешаете или отклоняете каждый запрос и можете отозвать доступ в настройках. С версии 0.3.2 Fabric отправляет анонимные счётчики использования — только количество и типы событий, без имён, путей и содержимого; отключить их можно в «Настройки → Делиться счётчиками использования», и это действует для всех приложений PassionCode.ai на вашем Mac.

Fabric — открытый код под GNU AGPL-3.0; для использования, которое AGPL не покрывает, коммерческую лицензию можно получить на passioncode.ai/business. Предварительная версия 0.3.4 собрана, подписана и нотаризована в CI из этого открытого кода.
