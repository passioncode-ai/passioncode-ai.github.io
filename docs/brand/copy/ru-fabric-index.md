## чем разговор

Агент может закончить задачу, а команда уже не помнит, зачем она была нужна. Контекст расходится по чатам, одни и те же решения приходится объяснять заново, а кому-то — снова собирать работу в одно целое.

### Перед первым запуском

Fabric запускает собственную локальную базу данных через Supabase CLI внутри Docker.

На macOS: запущенный Docker Desktop или OrbStack и Supabase CLI: brew install supabase/tap/supabase

На Windows: запущенный Docker Desktop с WSL2 и Supabase CLI: scoop install supabase

На Linux: запущенный Docker Engine и Supabase CLI

Claude Code или Codex CLI, в котором выполнен вход: через него агенты делают работу

Если Docker или CLI не установлены, при первом запуске Fabric скажет, чего не хватает. Посмотрите, с какими агентами для программирования работает Fabric и что каждый из них может в нём делать.

Пока нет на Windows и Linux: Fabric не проверяет, выполнен ли вход в агент для программирования, и прямо об этом говорит. Пока нет на Windows: подключение секрета облачного продукта через Project Observatory.

Это ранняя предварительная версия. В ней можно вести проекты, доску решений, задачи, цели, пульс работы и релизы с квитанциями. Чат с Fabric сохраняет ваши сообщения, но Fabric пока не отвечает. Новая версия не обновляет существующую базу данных сама, а подсказывает, какую команду выполнить. Агенты, зарегистрированные на этом Mac, могут через локальный хаб агентов Fabric запросить доступ к подключённому продукту, например к Fabric Inbox: вы разрешаете или отклоняете каждый запрос и можете отозвать доступ в настройках. С версии 0.3.2 Fabric отправляет анонимные счётчики использования: только количество и типы событий, без имён, путей и содержимого. Отключить их можно в разделе «Настройки → Делиться счётчиками использования», и это действует для всех приложений PassionCode.ai на вашем Mac.

Fabric — открытый код под GNU AGPL-3.0. Если ваш случай AGPL не покрывает, коммерческую лицензию можно получить на passioncode.ai/business. Предварительная версия 0.3.11 собрана, подписана и нотаризована в CI из этого открытого кода.
