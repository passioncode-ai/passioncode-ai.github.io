# Anleitungen zur Arbeit mit Agenten

Kurze Anleitungen zum Einrichten der Tools auf deinem Computer und zum Einführen von Agenten in deine Organisation

Jede Anleitung erklärt, was bei jedem Schritt passiert, bevor du ihn gehst. Sie helfen zwei Arten von Lesern: Menschen, die die Tools auf dem eigenen Computer einrichten, und Führungskräften, die Agenten in ein Unternehmen bringen.

## Wo anfangen

Auf deinem eigenen Computer: lies zuerst die Anleitung zur Einrichtung und führe dann den Befehl von der Seite „Loslegen“ aus.

Für dein Unternehmen: lies, wie die kostenlose einwöchige Analyse funktioniert, und dann, wie aus Agentenvorlagen deine Agenten werden.

### Warum Aufgaben zwischen Menschen liegen bleiben und was sich mit einem Agent ändert

Eine Aufgabe kann aktiv aussehen, obwohl sie darauf wartet, dass die nächste Person sie sieht, übernimmt oder an den Planer zurückgibt. Ein Agent verändert den Tagesrhythmus, indem er diese Prüfungen und Eskalationen automatisch übernimmt. Die Verantwortung und die Entscheidungen bleiben bei den Menschen.

Für Gründer und Leiter von Produktteams, deren Aufgaben zwischen Menschen warten und deren Planer Verantwortliche von Hand nachverfolgen.

### Warum dein Release immer wieder rutscht: was ein Team-Assessment zeigt

Ein Release geht erst raus, wenn auch alles rund um den Code bereit ist. Ein Team-Assessment liest, wie die Arbeit in den letzten 90 Tagen tatsächlich lief, und zeigt, wo sie wartete. So beseitigst du das Warten, statt das Team anzutreiben.
