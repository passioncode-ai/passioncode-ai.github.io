# Anleitungen zur Arbeit mit Agenten

Kurze Anleitungen zum Einrichten der Tools auf deinem Computer und zum Einführen von Agenten in deine Organisation

Jede Anleitung erklärt, was bei jedem Schritt passiert, bevor du ihn gehst. Sie helfen zwei Arten von Lesern: Menschen, die die Tools auf dem eigenen Computer einrichten, und Führungskräften, die Agenten in ein Unternehmen bringen.

## Wo anfangen

Auf deinem eigenen Computer: lies zuerst die Anleitung zur Einrichtung und führe dann den Befehl von der Seite „Loslegen“ aus.

Für dein Unternehmen: lies, wie die kostenlose einwöchige Analyse funktioniert, und dann, wie aus Agentenvorlagen deine Agenten werden.

### Wie die kostenlose einwöchige Analyse funktioniert

Ein Agent liest eine Woche lang mit reinem Lesezugriff, wie dein Unternehmen arbeitet. Am Ende bekommst du eine Karte davon, wie die Arbeit wirklich läuft, und ein fertiges Angebot dafür, was Agenten zuerst übernehmen sollten.
