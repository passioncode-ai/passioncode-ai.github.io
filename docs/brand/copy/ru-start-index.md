# От пустого Mac до первого агента

Хватит собирать агентов, которые гниют и не общаются друг с другом. Пять шагов, около двадцати минут, и каждый полезен сам по себе

Нужны Node.js 18+ и Claude Code или Codex Для Fabric нужен macOS на Apple silicon

## Шаги

01

### Установите скилы

Лаунчер PassionCode.ai устанавливает скилы Fabric Agent Adapter, Observatory Log и рабочие правила в ваш агент для программирования. Без аккаунта и без ключа.

npx @passioncode-ai/passioncode@latest update

Лаунчер 0.1.31 · после установки перезапустите агента · автоматические обновления включены; их можно отключить

02

### Добавьте Fabric

Fabric — ИИ-агент в роли CEO: у каждого проекта появляется единое место для цели, доски задач, решений и релизов. Это ранняя предварительная версия: ей нужны Docker и Supabase CLI, а чат сохраняет сообщения, но пока не отвечает.

03

### Создайте или адаптируйте агента

Попросите в Claude Code или Codex то, что вам нужно. Скил Fabric Agent Adapter соберёт сервис, совместимый с Fabric: контракт, дашборд, тесты и проверку соответствия.

создание Создай агента Fabric, который каждое утро проверяет отзывы о нашем приложении в сторе и готовит черновики ответов

адаптация Адаптируй этот репозиторий к Fabric

04

### Запустите и посмотрите

Fabric Dashboards показывает все локальные сервисы агентов в одном окне; ваш агент может запускать, останавливать и открывать их по MCP.

Скачать Fabric Dashboards

0.6.7

↓

claude mcp add --scope user fabric-dashboards -- "/Applications/Fabric Dashboards.app/Contents/Resources/bin/fabric-dashboards-mcp"

05

### Добавьте следующего агента и посмотрите на семью

Соберите следующего агента так же и дайте ему тот же проект в Fabric. Claude Code, Kilo Code и Hermes Agent, запущенные из Fabric, делят доску, память и передачи работы этого проекта: один продолжает с того места, где остановился другой. Какие агенты подключаются сегодня

## начатое до конца
