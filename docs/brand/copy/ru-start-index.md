## Шаги

01

### Установите навыки

Лаунчер PassionCode.ai ставит вашему агенту для программирования навыки (skills) Fabric Agent Adapter и Observatory Log, а также рабочие правила. Аккаунт и ключ не нужны. Fabric лаунчер не устанавливает: это следующий шаг, Fabric скачивается отдельно.

npx @passioncode-ai/passioncode@latest update

Лаунчер 0.1.39 · после установки перезапустите агента · автоматические обновления включены; их можно отключить

02

### Добавьте Fabric

Fabric — дом для ваших проектов и их агентов: в нём каждый проект хранит свою цель, доску задач, решения и релизы. На первом экране четыре действия: создать агента, адаптировать уже готового, открыть проект или создать новый. Это ранняя предварительная версия: для неё нужны Docker и Supabase CLI, а чат сохраняет сообщения, но пока не отвечает.

03

### Создайте или адаптируйте агента

Опишите в Claude Code или Codex, что вам нужно, или начните с действий «Создать» и «Адаптировать» в Fabric: работа в любом случае идёт в консоли вашего агента для программирования. Навык Fabric Agent Adapter сначала задаёт вопросы и показывает план, а уже потом что-то меняет; при адаптации все изменения идут в новую ветку fabric-adapter. В итоге у вас будут контракт, дашборд, тесты и отчёт о соответствии.

создание Создай агента Fabric, который каждое утро проверяет отзывы о нашем приложении в сторе и готовит черновики ответов

адаптация Адаптируй этот репозиторий к Fabric

04

### Запустите и посмотрите

Fabric Dashboards показывает все локальные сервисы агентов в одном окне; ваш агент может запускать, останавливать и открывать их по MCP.

Скачать Fabric Dashboards

0.7.5

↓

claude mcp add --scope user fabric-dashboards -- "/Applications/Fabric Dashboards.app/Contents/Resources/bin/fabric-dashboards-mcp"

05

### Добавьте следующего агента в тот же проект

Соберите следующего агента тем же способом и подключите его к тому же проекту в Fabric. У Claude Code, Kilo Code и Hermes Agent, запущенных из Fabric, общие доска, память и передачи работы этого проекта, поэтому один продолжает с того места, где остановился другой.
