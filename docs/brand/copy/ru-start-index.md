# От пустого Mac до первого агента

Хватит собирать агентов, которые гниют и не общаются друг с другом. Пять шагов, около двадцати минут — от первого агента до семьи, которую видно. Каждый шаг полезен сам по себе — остановитесь там, где результата уже достаточно

## Шаги

01

### Установите скилы

Лаунчер PassionCode.ai устанавливает скилы Fabric Agent Adapter, Observatory Log и рабочие правила в Claude Code, Codex и других поддерживаемых агентов. Без аккаунта и без ключа.

npx @passioncode-ai/passioncode@latest update

Лаунчер 0.1.31 · устанавливает компоненты семейства в зафиксированных версиях · после установки перезапустите агента. Автоматические обновления включены по умолчанию; их можно отключить, если хотите.

02

### Добавьте Fabric

Fabric — ИИ-агент в роли CEO: у каждого проекта появляется единое место для цели, доски задач, решений и релизов. Это ранняя предварительная версия: ей нужны Docker и Supabase CLI, а чат сохраняет сообщения, но пока не отвечает.

03

### Создайте или адаптируйте агента

Попросите в Claude Code или Codex то, что вам нужно. Скил Fabric Agent Adapter соберёт сервис, совместимый с Fabric: контракт, дашборд, тесты и проверку соответствия.

создание Создай агента Fabric, который каждое утро проверяет отзывы о нашем приложении в сторе и готовит черновики ответов

адаптация Адаптируй этот репозиторий к Fabric

Существующий агент, MCP-сервер или консольный инструмент сохраняет свой код; адаптер добавляет вокруг него то, что нужно Fabric. Быстрый старт адаптера · контракт

04

### Запустите и посмотрите

Fabric Dashboards показывает все локальные сервисы агентов в одном окне; ваш агент может запускать, останавливать и открывать их по MCP.

Скачать Fabric Dashboards

0.6.5

↓

claude mcp add --scope user fabric-dashboards -- "/Applications/Fabric Dashboards.app/Contents/Resources/bin/fabric-dashboards-mcp"

Затем добавьте то, что нужно вашей работе: Fabric Switchboard — когда агентам нужно несколько аккаунтов, Project Observatory — чтобы видеть, что изменилось во всех проектах, Fabric Inbox — для почты.

05

### Добавьте следующего агента и посмотрите на семью

Когда этого попросит работа, соберите следующего агента так же и дайте ему тот же проект в Fabric. Claude Code, Kilo Code и Hermes Agent, запущенные из Fabric, делят доску, память и передачи работы этого проекта: один продолжает с того места, где остановился другой. Fabric Dashboards показывает обоих, с их состоянием и расходами, в одном окне.

дальше Создай агента Fabric, который превращает подготовленные ответы на отзывы в еженедельную сводку для доски

Каждый новый агент входит в семью, которую вы уже видите, а не становится ещё одним скриптом, о котором надо помнить. Как растёт семья · какие агенты подключаются сегодня

## начатое до конца

Для изменений, которые делают ваши агенты, мы рекомендуем task-pipeline— отдельный скил с открытым кодом из семьи sshlg-skills. Он проводит изменение через этапы с проверками — от брифа и плана до тестов, деплоя и приёмки — и не идёт дальше, пока не пройдена каждая проверка.

## Пришлите pull request

Репозитории всех продуктов открыты. В каждом команда для тестов указана в AGENTS.md, а быстрый старт — в README; ваш агент для программирования прочитает оба и сделает остальное.

### Выберите репозиторий

Сделайте форк продукта, которым пользуетесь, или посмотрите всю организацию. Задачи с меткой — хорошее начало.

### Запустите его проверки

Прочитайте AGENTS.md репозитория и CONTRIBUTING.md организации, внесите изменение и запускайте команду тестов, пока она не пройдёт.

### Откройте pull request

Открывая его, вы соглашаетесь с CLA.md репозитория; отмечать ничего не нужно. Мы рассматриваем каждый pull request и отвечаем.
