## 你可以自己验算的算术题

你的团队每月在这些流程上花的工时，乘以智能体可合理接手的比例，再乘以每小时的成本。如果工作已经部分自动化，这个比例会更低，因为可以去掉的手工工作已经更少。

每周工时 × 4.33×智能体接手的比例×每小时综合成本

智能体可接手的比例，取决于目前工作的运行方式

示例： 每周 40 小时、大部分靠手工的工作，按每小时 $50 计，每月是 173 小时；智能体接手其中 25–50%，即 43–87 小时，或每月 $2,150–4,350。

这是估算，不是承诺。在任何推广之前，试点会对照你自己的基线，测出真实的数字。

08 / 常见问题

## 提问之前

费用是多少？

工具免费且开源。你支付的是我们为你做的工作——梳理、搭建、托管、支持——以及在需要时的商业许可证。我们了解流程之后，方案里会写明价格；没有固定套餐。

必须使用你们的云吗？

不必。工作空间可以运行在团队自己的电脑上、你自己的云账号里，或由 PassionCode.ai 托管。无论哪种方式，你的数据和模型账号都归你所有。

可以使用哪些模型和智能体？

任何一种。工作空间不绑定特定智能体：Claude Code、Kilo Code 和 Hermes Agent 目前已接入 Fabric，Codex 和 Cline 可在其中运行，并且更多智能体已在计划中。你已在使用的任何智能体、MCP 服务器或工具，都可以成为兼容 Fabric 的服务。

分析会监视我们的员工吗？

不会。分析针对的是智能体和流程的结果：运行了什么、花了多少、批准了什么。没有任何隐蔽的做法，被衡量的内容对相关的人都是可见的。

什么时候需要商业许可证？

工具采用 GNU AGPL-3.0 许可证。内部使用，以及你在相同许可证下公开的修改，无需任何额外手续。如果是包含这些工具的闭源产品，或是未公开源代码的修改版托管服务，则需要商业许可证。

这份表单里的回答会如何处理？

我们只用它们来回复和准备方案，并且保存不超过 24 个月。隐私声明中有详细说明。
