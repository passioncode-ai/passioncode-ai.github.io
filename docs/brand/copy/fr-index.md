07 / QUESTIONS

## Les questions qu’on nous pose d’abord

PassionCode.ai est-il gratuit ?

Oui. Chaque outil est open source sous licence GNU AGPL-3.0 : vous pouvez le télécharger, l’utiliser, l’étudier et le modifier gratuitement. Une licence commerciale est disponible si vous l’intégrez à un produit fermé ou si vous exploitez une version modifiée en service hébergé sans en publier le code source.

Avec quels agents fonctionne-t-il ?

Il n’est lié à aucun agent. Claude Code, Kilo Code et Hermes Agent se connectent déjà à Fabric, Codex et Cline tournent à l’intérieur, et d’autres sont prévus : la liste complète, par niveau. Avec Fabric Agent Adapter, n’importe quel agent, serveur MCP ou outil en ligne de commande peut devenir un service compatible avec Fabric.

Comment transformer un projet ou un agent existant en agent Fabric ?

Installez le lanceur PassionCode.ai (npx @passioncode-ai/passioncode@latest update), puis demandez à votre agent de code d’adapter le projet à Fabric. Le skill Fabric Agent Adapter en fait un service doté d’un contrat, d’un tableau de bord et d’un contrôle de conformité. Le guide détaille les étapes.

Fabric crée-t-il des agents tout seul ?

Pas encore. Fabric est en préversion : il conserve le tableau des tâches, les décisions et les versions de chaque projet, et sa conversation ne répond pas encore. Créer des agents à partir d’une conversation, c’est la direction ; aujourd’hui, c’est votre agent de code qui le fait, avec le skill Fabric Agent Adapter.

Où vont mes données ?

Votre travail reste sur vos ordinateurs et dans vos propres comptes cloud. Fabric Switchboard et, depuis la version 0.3.2, Fabric envoient des compteurs d’utilisation anonymes : uniquement des nombres et des types, jamais de noms, de chemins ni de contenu. Désactivez-les dans la fenêtre À propos de Switchboard ou dans les réglages de Fabric. Ce qui est envoyé, précisément.

PassionCode.ai peut-il mettre cela en place dans mon entreprise ?

Oui. Décrivez votre équipe et vos processus: nous vous répondons avec une estimation et une proposition, soit un accompagnement à la mise en place, soit un espace de travail que nous construisons et gérons pour vous.
