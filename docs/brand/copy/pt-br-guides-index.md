# Guias para trabalhar com agentes

Guias curtos para configurar as ferramentas no seu computador e para levar agentes à sua organização

Cada guia explica o que acontece em cada etapa antes de você chegar a ela. Eles ajudam dois tipos de leitores: quem configura as ferramentas no próprio computador e gestores que levam agentes para uma empresa.

## Por onde começar

No seu computador: leia primeiro o guia de configuração e depois rode o comando da página “Começar”.

Para a sua empresa: leia como funciona a avaliação gratuita de uma semana e depois como os modelos de agentes viram os seus agentes.

### Como funciona a avaliação gratuita de uma semana

Um agente lê como a sua empresa funciona durante uma semana, com acesso somente leitura. No final, você recebe um mapa de como o trabalho realmente acontece e uma proposta pronta do que os agentes devem assumir primeiro.
