01 / CE QU’IL FAIT

## Ce qu’il fait

Un seul lieu pour les identitésLes comptes de messagerie et les bots vivent dans un seul service, et aucun autre agent ne les détient.

Des autorisations par agentChaque agent n’obtient que ce dont il a besoin : lire, chercher, envoyer ou gérer un groupe.

Une personne approuve les envoisLes messages attendent l’approbation d’une personne, sauf si le propriétaire a fixé une règle permanente.

02 / À QUI IL S’ADRESSE

## À qui il s’adresse

Pour les organisations dont les agents parlent aux gens sur Telegram et ne doivent pas détenir chacun leur propre compte.

### Ce que vous obtenez

Pas de jetons de bot éparpillés entre les projets

Une trace de chaque message envoyé

Un seul interrupteur qui arrête tous les envois

03 / COMMENT IL EST ASSEMBLÉ

## Comment un modèle

## devient votre agent

Le modèle contient ce que nous avons appris en faisant tourner des agents de ce type. Notre agent ingénieur l’assemble pour votre organisation ; les détails sont fournis sur demande.

01

### Nous partons de vos processus

Vous nous dites ce que l’agent doit faire. Nous examinons le travail qu’il reprend, les systèmes dont il a besoin et qui approuve quoi.

02

### Notre agent ingénieur l’assemble

Il prend le modèle adapté, connecte vos systèmes avec les accès que vous accordez, et fixe vos règles et vos limites de dépenses.

03

### Il tourne là où vous le choisissez

Sur vos machines ou dans votre propre cloud, avec vos clés. Chaque agent affiche son état et ses dépenses, et une personne approuve ce qui demande une personne.
