01 / CE QU’IL FAIT

## Ce qu’il fait

Des réponses vérifiéesChaque brouillon est vérifié par rapport à votre base de connaissances et par un second modèle avant d’être envoyé.

Personne ne reste en attenteUne question à laquelle il ne peut pas répondre devient une passation, une fiche pour votre équipe et une relance.

Apprend de vos équipesUne réponse donnée par une personne retourne dans la base de connaissances.

02 / À QUI IL S’ADRESSE

## À qui il s’adresse

Pour les équipes dont la boîte de support, le chat communautaire ou le bot d’aide n’est jamais entièrement couvert.

### Ce que vous obtenez

Des premières réponses plus rapides dans toutes les langues

Des lacunes visibles dans votre base de connaissances

Une qualité mesurée chaque jour

03 / COMMENT IL EST ASSEMBLÉ

## Comment un modèle

## devient votre agent

Le modèle contient ce que nous avons appris en faisant tourner des agents de ce type. Notre agent ingénieur l’assemble pour votre organisation ; les détails sont fournis sur demande.

01

### Nous partons de vos processus

Vous nous dites ce que l’agent doit faire. Nous examinons le travail qu’il reprend, les systèmes dont il a besoin et qui approuve quoi.

02

### Notre agent ingénieur l’assemble

Il prend le modèle adapté, connecte vos systèmes avec les accès que vous accordez, et fixe vos règles et vos limites de dépenses.

03

### Il tourne là où vous le choisissez

Sur vos machines ou dans votre propre cloud, avec vos clés. Chaque agent affiche son état et ses dépenses, et une personne approuve ce qui demande une personne.
