# Monte seu ambiente de trabalho com agentes em 20 minutos

O que acontece em cada passo da configuração das ferramentas no seu próprio computador, do comando único ao seu primeiro agente e ao seguinte.

Sergey Sheleg, cofundador da PassionCode.ai

## O que você precisa

Um computador com Node.js 18 ou mais recente, e Claude Code ou Codex. O Fabric, a casa dos seus projetos e dos agentes deles, é uma prévia inicial e também requer o Docker e a Supabase CLI em todos os sistemas. Tudo é de código aberto e gratuito para uso pessoal.

## Execute um comando

No macOS, um comando instala as ferramentas que você escolher a partir das versões assinadas, conecta os servidores MCP delas ao seu agente de programação e adiciona as skills. No Windows e no Linux, primeiro baixe os apps nas páginas deles e depois execute o mesmo comando para as skills e os servidores MCP. Ele não instala nada cuja assinatura ou checksum falhe. Você também pode passar a tarefa ao seu agente de programação: o comando e um prompt para o seu agente de programação estão na página Primeiros passos.

## Reinicie seu agente de programação e verifique

Reinicie o Claude Code ou o Codex para que ele carregue as novas ferramentas. Execute o mesmo comando de novo, ou o doctor para verificar sem mudar nada: ele diz o que está configurado, o que falta e os passos que só você pode dar, como entrar na sua conta.

## Crie ou adapte seu primeiro agente

Peça ao seu agente de programação o que você precisa, em palavras simples, ou comece pelas ações de criar e adaptar do Fabric. A skill Fabric Agent Adapter faz as perguntas primeiro e mostra o plano antes de mudar qualquer coisa. Você recebe um agente com contrato, painel e testes.

## Veja-o funcionando

O Fabric Dashboards mostra cada serviço de agente local em uma só janela: o que ele está fazendo e quanto gasta. Seu agente de programação pode iniciá-los, pará-los e abri-los para você.

## Adicione o próximo agente ao mesmo projeto

Crie o próximo agente do mesmo jeito e dê a ele o mesmo projeto no Fabric. Agentes conectados ao Fabric compartilham o quadro, a memória e as passagens de trabalho de um projeto, então um continua de onde o outro parou.

## Se algo não funcionar

Execute o comando de novo: em um computador que já está configurado, ele verifica tudo, corrige o que está errado e mostra o que mudou. A página de cada produto lista os requisitos e os limites dele.
