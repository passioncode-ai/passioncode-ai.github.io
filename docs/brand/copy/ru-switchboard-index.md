## раньше, чем работа

Длинная сессия может упереться в лимит аккаунта на середине задачи. И работа стоит, пока вы выходите, ищете другой аккаунт и входите снова.

Switchboard не даёт работе остановиться. Когда включена ротация, следующий запрос уходит на другой аккаунт из того же пула, а сессия остаётся открытой.

01 / АККАУНТЫ

### Начните с того, что есть

Явно сохраните текущий аккаунт CLI, войдите через официальный CLI или импортируйте профили Claude Swap. Вы сами выбираете, что перенести в Switchboard.

02 / ГРАНИЦЫ

### Рабочее остаётся рабочим

Объединяйте аккаунты в пулы, например рабочий и личный. Маршрутизация не выходит за пределы одного провайдера и пула.

03 / ИСПОЛЬЗОВАНИЕ

### Свои лимиты — на виду

Смотрите окна квот, которые сообщают провайдеры, время сброса и давность каждой проверки. Неподдерживаемое или неизвестное использование явно помечено.

04 / ПЕРЕКЛЮЧЕНИЕ

### Выбирайте, куда уйдёт следующий запрос

Выберите управляемый маршрут или включите ротацию с учётом квот. Ответ, который уже идёт, остаётся на том аккаунте, с которого начался.

05 / ЛОКАЛЬНОЕ ХРАНЕНИЕ

### Учётные данные — на вашей машине

Сохранённые секреты хранятся в Связке ключей macOS или в Windows DPAPI. Изолированные запуски CLI создают локальную копию токена доступа, которая нужна официальному клиенту.

06 / ВАШ СПОСОБ РАБОТЫ

### Окно или терминал — как удобнее

Приложение и CLI работают на одной основе. Для управляемых сессий держите запущенным приложение или switchboard serve.

## свои лимиты

В Switchboard есть switchboard mcp — локальный MCP-сервер. Claude Code, Codex или другой MCP-клиент может узнать, сколько квоты осталось, и перевести следующий запрос на другой аккаунт. Ни один инструмент не принимает и не возвращает учётные данные.

01 / ИСПОЛЬЗОВАНИЕ

### Узнать остаток

Оставшаяся квота по каждому аккаунту и окну — со временем сброса и давностью каждой проверки. Неизвестное использование так и помечается как неизвестное, а не как ноль.

02 / ПЕРЕКЛЮЧЕНИЕ

### Переключиться до лимита

Агент может выбрать аккаунт для следующего запроса своей сессии — в пределах того же провайдера и пула. Чтобы сменить вход Claude Code для всех сессий на Mac, нужен явный флаг global.

03 / ПРАВИЛА ПРОЕКТА

### Правила проекта — по желанию

Если хотите, запускайте папку проекта на выбранном аккаунте. Правила видны в приложении, их можно приостановить или ограничить сроком, и они никогда не останавливают ротацию.

01

### Запуск из Switchboard

Сессии, запущенные из приложения или CLI, получают инструменты, если CLI switchboard доступен. Изолированные сессии получают инструменты только для чтения. На macOS панель «Агенты» связывает CLI внутри приложения с ~/.local/bin.

## Что важно различать

Switchboard заменяет Claude Code или Codex?

Нет. Он управляет аккаунтами и запускает официальные CLI. Для входа и сессий установите Claude Code или Codex отдельно. Подписка провайдера и кредиты API в Switchboard не входят.

Он сам меняет мой текущий аккаунт CLI?

Сохранение — явное действие. Выбор управляемого маршрута отделён от активации аккаунта в самом CLI. Активация аккаунта Claude в CLI и автоматическая ротация включаются только по вашему выбору; прочитайте подтверждение, прежде чем их включить.

Чем управляемая сессия отличается от изолированной?

Управляемые сессии отправляют запросы через локальный прокси, и следующие запросы идут по выбранному вами маршруту. Изолированные сессии подключаются напрямую из отдельного каталога аккаунта; последующий выбор маршрута на них не влияет.

Switchboard и Fabric — это одно и то же?

Switchboard — инструмент управления аккаунтами, доступный уже сегодня. Fabric — наш ИИ-агент в роли CEO, сейчас в ранней предварительной версии; его задача — координировать агентов и проекты. Оба входят в набор инструментов PassionCode. Посмотрите, что мы строим в Fabric.

Какие агенты работают со Switchboard?

Claude Code, Codex и другие популярные агенты для программирования — Hermes, Kilo Code, Cline, Goose, OpenCode и не только. Все 30 и как подключается каждый.

Может ли у проекта быть свой набор аккаунтов?

Да. Создайте проект, добавьте его папки — например, несколько связанных репозиториев — и выберите его аккаунты. Сессии, запущенные из этих папок, используют только эти аккаунты, автопереключение не выходит за их пределы, а агенты из других проектов на них никогда не переключаются.

Switchboard отправляет какие-нибудь данные?

Релизные сборки считают установки, дни использования и число подключённых аккаунтов по провайдерам и типам. Они никогда не отправляют названия аккаунтов, адреса e-mail, входы, названия пулов и то, что вы делаете со своими аккаунтами. Случайный номер установки, общий для инструментов PassionCode.ai на вашем компьютере, позволяет посчитать одного человека один раз. Отключается в «О программе» → «Отправлять анонимную статистику использования»; переключатель действует на все инструменты PassionCode.ai. Что именно отправляется.

Можно ли изучить или собрать его самому?

Да. Switchboard — открытый код под GNU AGPL-3.0. Для использования, которое AGPL не покрывает, коммерческую лицензию можно получить на passioncode.ai/business. Релизы до v0.3.1-beta.1 включительно вышли под MIT и остаются доступны под ней. Текущая версия для скачивания, 0.6.16, выпущена под AGPL. v0.4.0-beta.1 вышла под PolyForm Noncommercial или Internal Use и сохраняет эту лицензию. В репозитории есть инструкции по сборке, исходный код, тесты и подтверждения релизов.
