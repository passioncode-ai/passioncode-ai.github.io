## Лимиты заканчиваются

## раньше, чем работа

Длинная сессия может упереться в лимит аккаунта на середине задачи. Тогда работа стоит, пока вы выходите из аккаунта, ищете другой и входите снова.

Switchboard не даёт работе остановиться. Когда автопереключение включено, следующий запрос уходит на другой аккаунт из того же пула, а сессия остаётся открытой.

01 / АККАУНТЫ

### Начните с того, что есть

Сохраните текущий аккаунт CLI, войдите через официальный CLI или импортируйте профили Claude Swap. Что перенести в Switchboard, решаете вы.

02 / ГРАНИЦЫ

### Рабочее остаётся рабочим

Объединяйте аккаунты в пулы, например рабочий и личный. Запросы переключаются только между аккаунтами одного провайдера и одного пула.

03 / ИСПОЛЬЗОВАНИЕ

### Ваши лимиты на виду

Смотрите окна квот по данным провайдеров, время сброса и то, насколько свежа каждая проверка. Если расход неизвестен или провайдер его не сообщает, это прямо помечено.

04 / ПЕРЕКЛЮЧЕНИЕ

### Выбирайте, куда уйдёт следующий запрос

Выберите управляемый маршрут или включите автопереключение с учётом квот. Ответ, который уже идёт, остаётся на том аккаунте, с которого начался.

05 / ЛОКАЛЬНОЕ ХРАНЕНИЕ

### Учётные данные — на вашей машине

Секреты хранятся в Связке ключей macOS или в Windows DPAPI. Для изолированного запуска CLI создаётся локальная копия токена доступа: без неё официальный клиент не работает.

06 / ВАШ СПОСОБ РАБОТЫ

### Окно или терминал — как удобнее

Приложение и CLI работают на одном ядре. Для управляемых сессий держите запущенным приложение или switchboard serve.

## свои лимиты

В Switchboard есть switchboard mcp — локальный MCP-сервер. Claude Code, Codex или другой MCP-клиент может узнать, сколько квоты осталось, и перевести следующий запрос на другой аккаунт. Ни один инструмент не принимает и не возвращает учётные данные.

01 / ИСПОЛЬЗОВАНИЕ

### Узнать остаток

Оставшаяся квота по каждому аккаунту и окну, время сброса и давность каждой проверки. Если расход неизвестен, так и написано, а не показан ноль.

02 / ПЕРЕКЛЮЧЕНИЕ

### Переключиться до лимита

Агент может выбрать аккаунт для следующего запроса своей сессии — в пределах того же провайдера и пула. Чтобы сменить вход Claude Code для всех сессий на Mac, нужен явный флаг global.

03 / ПРАВИЛА ПРОЕКТА

### Необязательные правила проекта

Если хотите, сессии в папке проекта будут начинаться на выбранном аккаунте. Правила видны в приложении, их можно приостановить или ограничить сроком, и они никогда не останавливают автопереключение.

01

### Запуск из Switchboard

Сессии, запущенные из приложения или CLI, получают инструменты, если CLI switchboard доступен. Изолированные сессии получают инструменты только для чтения. На macOS панель «Агенты» связывает CLI внутри приложения с ~/.local/bin.

## Что важно различать

Switchboard заменяет Claude Code или Codex?

Нет. Он управляет аккаунтами и запускает официальные CLI. Для входа и сессий установите Claude Code или Codex отдельно. Подписка провайдера и кредиты API в Switchboard не входят.

Он сам меняет мой текущий аккаунт CLI?

Аккаунт сохраняется только по вашей команде. Выбор управляемого маршрута и активация аккаунта в самом CLI — разные действия. Активацию аккаунта Claude в CLI и автопереключение вы включаете сами; перед этим прочитайте подтверждение.

Чем управляемая сессия отличается от изолированной?

Управляемые сессии отправляют запросы через локальный прокси, и следующие запросы идут по выбранному вами маршруту. Изолированные сессии подключаются напрямую, с отдельным домашним каталогом аккаунта; последующий выбор маршрута на них не влияет.

Switchboard и Fabric — это одно и то же?

Switchboard — инструмент для управления аккаунтами, доступный уже сегодня. Fabric — дом для ваших проектов и их агентов, пока в ранней предварительной версии. Оба входят в набор инструментов PassionCode. Что мы строим в Fabric.

Какие агенты работают со Switchboard?

Claude Code, Codex и другие популярные агенты для программирования — Hermes, Kilo Code, Cline, Goose, OpenCode и не только. Все 30 агентов и как подключить каждый.

Может ли у проекта быть свой набор аккаунтов?

Да. Создайте проект, добавьте его папки (например, несколько связанных репозиториев) и выберите его аккаунты. Сессии, запущенные из этих папок, используют только эти аккаунты, автопереключение не выходит за их пределы, а агенты из других проектов на них никогда не переключаются.

Switchboard отправляет какие-нибудь данные?

Релизные сборки считают установки, дни использования и число подключённых аккаунтов по провайдерам и типам. Они никогда не отправляют названия аккаунтов, адреса почты, данные для входа, названия пулов и то, что вы делаете со своими аккаунтами. Случайный номер установки, общий для инструментов PassionCode.ai на вашем компьютере, позволяет посчитать одного человека один раз. Отключить статистику можно в «О программе» → «Отправлять анонимную статистику использования»; переключатель действует на все инструменты PassionCode.ai. Что именно отправляется.

Можно ли изучить код или собрать Switchboard самому?

Да. Switchboard — открытый код под GNU AGPL-3.0. Для использования, которое AGPL не покрывает, коммерческую лицензию можно получить на passioncode.ai/business. Релизы до v0.3.1-beta.1 включительно вышли под лицензией MIT и по-прежнему доступны на её условиях. Текущая версия для скачивания, 0.6.33, выпущена под AGPL. v0.4.0-beta.1 вышла под PolyForm Noncommercial или Internal Use и сохраняет эту лицензию. В репозитории есть инструкции по сборке, исходный код, тесты и подтверждения релизов.
