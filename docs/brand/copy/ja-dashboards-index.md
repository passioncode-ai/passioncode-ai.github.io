01 / 作業を見える状態に

## 作業を担うツールへの

## 窓口

Fabric Dashboards は、Mac 上の対応サービスを検出します。各サービスの役割はそのままで、確認と操作のための共通の場所が加わります。

### 対応が必要なものを把握

サービスの状態、最新のアクティビティ、要対応の項目がまとめて表示されます。応答の遅いプローブが、すぐに障害と判定されることはありません。

### 実際のダッシュボードを開く

各サービス自身のインターフェースが、サインイン済みの状態でアプリ内に開きます。Project Observatory は、今すぐ使える対応サービスの一つです。

### 次のステップに進む

サービスの開始、停止、再起動、ログの確認、コントラクトが公開する操作の実行ができます。Dashboards を終了しても、サービスは動き続けます。

## そして信頼できるアップデート

0.6.0（10 月 6 日）から 0.6.5（2026 年 10 月 8 日）までの 0.6 系リリースで追加された内容です。

### 支出の上限をすべて表示

支出ページには、各エージェントに適用された上限が一覧で表示されます。作業が止まった、または上限を超えたもので最も対応が必要なものは赤、80% に達したものは黄色で表示され、エージェントを展開すると、すべての上限と、その期間、使用額が確認できます。エージェントも MCP 経由で同じ一覧を読み取れます。

### ダッシュボードの隣にエージェントコンソール

サービスのダッシュボードの横で本物のターミナルが開き、そのエージェントのリポジトリで Claude Code、Codex、その他のランタイムを実行します。Fabric Switchboard がフォルダをプロジェクトに紐付けている場合、セッションはそのプロジェクトのアカウントで始まります。

### 事前に検証されるアップデート

アプリは自動で更新されます。リリースは、組織の署名を備え、チェックサムと一致している場合にのみインストールされ、コンソールやコマンドの実行中は待機します。自動インストールは設定でオフにできます。

### 常に最新のファミリー

設定 → Estate updates では、Fabric Agent Contract と PassionCode.ai のスキルを監視し、公開元を確認したうえで、スキルをバックグラウンドで更新できます。このスイッチは初期状態ではオフです。

### 英語またはロシア語

設定 → 言語：Mac の設定に合わせるか、English または Русский を選べます。ウィンドウ、メニュー、トレイは同時に切り替わります。

## 同じサービスを

## エージェントから使う

アプリの MCP サーバーをお使いのクライアントに登録します。エージェントは、サービスの一覧取得、ダッシュボードへのリンク取得、アプリのルールで公開された操作の実行ができます。

claude mcp add --scope user fabric-dashboards -- "/Applications/Fabric Dashboards.app/Contents/Resources/bin/fabric-dashboards-mcp"

アプリを Applications にインストールしたら、エージェントに次の呼び出しを依頼します：list_services。結果が空なら、サービスがまだインストールされていません。他の MCP クライアントでも、同じ実行ファイルを stdio サーバーとして実行できます。次も参照してください：MCP セットアップガイド。

04 / 知っておきたいこと

## 今の環境にそのまま加えられます

Fabric は必要ですか？

いいえ。Fabric Dashboards は単独で使えます。Fabric のツールの一つで、Fabric の早期プレビュー版を使う前でも、対応サービスを表示できます。

どのサービスが表示されますか？

次のローカルディスクリプターを公開するサービスです：fabric-service/0.1。Project Observatory が対応しています。プロトコルはFabric Agent Contractで定義されており、Adapter が実装を支援します。

オープンソースですか？

Fabric Dashboards は GNU AGPL-3.0 のオープンソースです。商用ライセンスもご用意しています：passioncode.ai/business。リリース 0.1.0 は MIT のままです。0.2.0 と 0.3.0 は PolyForm Noncommercial または Internal Use のままです。リリース 0.3.1 が AGPL 下での最初のリリースです。
