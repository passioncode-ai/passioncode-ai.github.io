TROIS FAÇONS DE SE CONNECTER

## Comment chaque agent se connecte

Chaque agent ci-dessous peut utiliser les outils de Switchboard : il voit quel compte traite ses requêtes et combien de quota il reste, et il peut changer de compte. Les agents qui acceptent un point d’accès personnalisé peuvent aussi envoyer leurs requêtes via Switchboard, qui change de compte à leur place. Certains peuvent être lancés directement depuis Switchboard.

Outils seulement. L’agent se connecte aux outils de Switchboard ; ses requêtes partent vers son propre service.

Via Switchboard. À configurer une seule fois dans l’agent ; Switchboard affiche les lignes exactes.

Lancement depuis Switchboard. Switchboard lance l’agent dans un dossier de projet, avec les comptes de ce dossier.

Les connexions par abonnement restent réservées à Claude Code et Codex, comme l’exigent Anthropic et OpenAI. Les autres agents utilisent des comptes à clé d’API. Les comptes d’un projet ne servent que les dossiers de ce projet.
