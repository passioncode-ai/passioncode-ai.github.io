# SEO / AEO build-time brief: agent templates, guides and blog (SITE-056)

- **Date:** 2026-11-08
- **What is being built:** new sections of a live site: `/agents/` (the agent template marketplace and one page per
  template), `/guides/` (three guides), `/blog/` (two posts)
- **Markets / languages:** the site's ten languages (`i18n/locales.json`): English at `/`, then `/ru/`, `/de/`,
  `/fr/`, `/pl/`, `/ko/`, `/es/`, `/pt-br/`, `/zh-hans/`, `/ja/`; every new page exists in each
- **Live today:** the rest of passioncode.ai (an audit after this lands covers it; the first audit after the deploy
  is this brief's acceptance run)
- **Owners:** copy · this repository's agent (English source, catalogs) and Copylot checks · design: the existing
  design system (`styles.css`, `design-system/`) · engineering: `scripts/build-content-pages.mjs`,
  `scripts/build-locale.mjs` · analytics: `docs/analytics/events.md`

This brief records decisions, not findings. Nothing here is observed yet; each row names the audit section that will
verify it after launch. A row the project does not need stays, marked `n/a` with a reason.

Written with the `seo-aeo-audit` skill's brief mode (`references/build-time.md`, version 0.32.4) before the pages were
built (operator, 2026-11-08: a marketplace of agent templates, a guides section and a blog, then indexing).

## Do not build

| Idea | Why not |
|---|---|
| A page per source agent, or any source agent's, client's or organization's name | private (the template library is closed); one page per kind of agent |
| Prompts, code, architecture, library stack or test counts per template | private; the public page says what the agent does and how it is assembled in general terms |
| A price, a timeline or an assembly time per template | not measured, not decided; the estimate comes with the request (`/business/`) |
| Client-side search or filters on `/agents/` | 18 items fit four static groups; filtering would hide content from crawlers |
| A new contact form | the existing request on `/business/#request` is the one path |
