# Public flows

## FLW-01 — Discover and download
Homepage → primary Explore the tools → homepage available tools; secondary download → Switchboard detail/download → read OS, format and limits → Before you open it (official CLI, OS, Windows limits) → macOS or Windows link → GitHub archive → compare with the SHA-256 on the page. From 0.4: For agents → connect command or launch from Switchboard. Alternatives: release notes/checksums, installation guide, all releases; unavailable network or asset → retry or use releases/support. The site does not observe OS installation.

## FLW-02 — Inspect and reuse
Homepage/detail → source repository and its source-available license (PolyForm Noncommercial or Internal Use; commercial license on request; earlier MIT releases stay MIT); footer → design system → canonical CSS/source. Fabric's source stays private; its page offers the signed macOS preview through `/fabric/download/macos` and its public release notes, never a source link.

## FLW-03 — Understand and follow
Homepage work cycle → available Switchboard / Fabric early preview → individual product page → Fabric requirements and download. Build pipeline explains status without dates or implied integration. Fabric detail → homepage About → verified author Twitter. Alternative: inspect public code/release notes from the Source section (Switchboard, Observatory, Fabric Dashboards); no private repository link or sign-up barrier. Mobile navigation exposes the same destinations.
