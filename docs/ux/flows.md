# Public flows

## FLW-01 — Discover and download
Homepage → primary Explore the tools → homepage available tools; secondary download → Switchboard detail/download → read OS, format and limits → macOS or Windows link → GitHub archive. Alternatives: release notes/checksums, installation guide, all releases; unavailable network or asset → retry or use releases/support. The site does not observe OS installation.

## FLW-02 — Inspect and reuse
Homepage/detail → source repository and MIT license; footer → design system → canonical CSS/source. Fabric's source stays private; its page offers the signed macOS preview through `/fabric/download/macos` and its public release notes, never a source link.

## FLW-03 — Understand and follow
Homepage work cycle → available Switchboard / Fabric early preview → individual product page → Fabric requirements and download. Build pipeline explains status without dates or implied integration. Fabric detail → homepage About → verified author Twitter. Alternative: inspect public code/release notes from Open source; no private repository link or sign-up barrier. Mobile navigation exposes the same destinations.
