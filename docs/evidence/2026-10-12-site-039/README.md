## The video

The player moved from the end of How it works (`#how`) to directly under the hero (`index.html`, `#video`), in every
language (the other nine are generated by `npm run locales`). The hero's text stays the page's answer above the fold,
for readers and for crawlers; the video is the next thing on the page.

- Nothing about the player changed: native controls, `preload="none"` (only the poster loads before play), no
  autoplay, loop or mute, `playsinline`, captions on by default in the page's language, WebM then MP4, the
  `width`/`height` attributes and the CSS `aspect-ratio: 16 / 9` reserve its box, so it does not shift the page.
  The files were not re-encoded or regenerated.
- The caption line now reads "How it works in under a minute: narrated, with captions. The screens show sample data;
  the coding agent's console is a written example" (it said "The steps above…", which stopped being true), in all
  nine catalogs.
- `scripts/check-site.mjs` now requires the player directly under the hero, before `#why`, and not inside `#how`.
