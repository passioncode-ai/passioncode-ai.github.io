Self-Improving Agents Move From Models to Harnesses

This research treats improvement as an engineering problem around a frozen model: edit prompts, skills, tool rules and memory, test the result, and reject regressions. OpenAI's usage figures show why reliability and cost discipline matter as agents take on longer research tasks.

PassionCode.ai research desk

GUARD: Stabilizing Recursive Self-Improvement

arXiv 2611.23476

GUARD keeps a frozen base model stable while continually evolving the harness around it.

  • The editable harness contains prompts, skills, tool rules and memory, with no external reference grader required.
  • Each round grades trajectories against pre-execution self-checks, pins mastered rules, prioritizes newly broken behaviors and ranks parallel edits by critic-free group-relative fitness.
  • A Soft-HURT gate promotes an edit only when its gains outweigh its regressions, and the reported benchmarks show consistent improvement without catastrophic forgetting or memory pollution while cutting deployment token usage.

What we can adopt: Gate harness edits on self-check results and group-relative candidate fitness, then roll out only edits whose gains outweigh their regressions.

Do LLM Agents Still Need to Be Told How to Self-Improve?

arXiv 2611.23219

Sufficiently capable frozen agents can design useful self-improvement procedures without a prescribed learning loop.

  • The agent receives a compute budget and tools for collecting experience and updating text documents, with no externally imposed loop or real-world data.
  • Its strategies align with classic cognitive frameworks for self-regulated learning and with self-generated curricula.
  • The resulting text artifacts improve external benchmarks across different game horizons, mechanics and 3D navigation.

What we can adopt: Give strong agents a bounded experimentation sandbox and evaluate their learned text artifacts on held-out tasks before deploying them.

The Components of Agent Memory

Anthropic research

Agent memory works best when it consolidates validated rules rather than archiving every event.

  • Anthropic describes offline consolidation during idle time, building on sleep-time compute from Letta and UC Berkeley, and calls log reflection dreaming.
  • On Continual Learning Bench 1.0, Claude Opus 5 was Anthropic's first tested model to close the learning loop with memory, while Opus 5.5 and Sonnet 5.5 also closed it and scored about the same as Opus 5 with memory.
  • A contrasting Pokémon Red run shows the failure mode: Sonnet 3.7 wrote 413 memory files across 225 folders and earned one badge.

What we can adopt: Schedule idle-time memory consolidation that extracts validated rules and repairs notes instead of appending an unfiltered event log.

Research Acceleration: The Jagged Frontier

OpenAI research

Autonomous research capability and usage rose sharply, but success remains highly dependent on the task.

  • From March to October, estimated success rose from 23% to 46% for tasks requiring two to four hours of human work and from 13% to 35% for tasks requiring four to eight hours.
  • Success was 79% for monitoring training runs, 35% for launching them and 25% for writing inference and serving code.
  • Median daily usage reached $2,400 per researcher at API list prices in October, up 62% from September, while agent workdays rose from 0.5 to 5.7 per researcher, an elevenfold increase.

What we can adopt: Track autonomous success and spending separately for each research task type before expanding agent autonomy.

Large-Scale Harness Evolution Results

Elvis Saravia

A large harness-evolution study reports broad population gains alongside lower cost on jointly solved tasks.

  • Population-mean success rose in all six model-benchmark settings, with single agents gaining up to 11.2 points.
  • On SWE-bench Multilingual, one evolved agent gained 5.0 points and spent 38.5% less on tasks both versions solved.
  • The work covered nearly 35,000 agent runs on SWE-bench Verified and Terminal-Bench and varied three decisions separately.

What we can adopt: Evaluate harness decisions independently across a population of runs, and compare both success and cost on tasks solved by the baseline.

A Curriculum for Post-Training Agents

Hugging Face

The curriculum moves agents from imitation of correct traces toward group-relative reinforcement learning in environments and harnesses.

  • Its five steps are SFT on agent traces, distillation, RL with GRPO, RL environments and harnesses at scale.
  • SFT exposes the model only to correct traces, so it has not learned how to recover when its own task attempt goes wrong.
  • GRPO samples several answers per prompt, scores them and raises the probability of answers above the group average.

What we can adopt: Use SFT for basic execution, then train in environments where agents generate and score their own attempts rather than relying only on correct demonstrations.

AI Papers of the Week

DAIR.AI

The roundup maps complementary approaches to agent improvement through memory, routine decisions, skill repair, harness validation and safer updates.

  • ARISE learns from enterprise-agent failures without changing model weights, tools or workflow code, while AnyS1 trains one 4B System-1 model on decision points mined from human-written skills.
  • Selective maintenance checks and repairs stored skill state after environment changes without extra model calls.
  • A self-rewriting harness framework uses four editable runtime components and a diagnose, propose, validate and deploy loop tested on SWE-bench Lite, while Safe Personal RSI decides whether a proposed instruction update is safe for the Kicker health assistant.
  • The Resolution Hypothesis argues that noisy evaluations stall evolution because they cannot distinguish better candidates from worse ones.

What we can adopt: Prefer failure-derived memory and selective skill repair before changing weights, and make candidate evaluation reliable enough to resolve real improvements.

What we can adopt

  • Gate every harness edit on measured gains and regressions.
  • Let capable agents design curricula inside bounded, transferable test environments.
  • Consolidate memory offline into validated rules instead of retaining every event.
  • Track success, token use and dollar cost by task before expanding autonomy.
